# GLM Coding Guard

这是一个面向 `https://www.bigmodel.cn/glm-coding` 的油猴脚本，用来做三件事：

- 在每天开售前自动进入监控窗口
- 发现“订阅/购买”按钮后高亮、声音提醒、桌面通知
- 可选自动点击第一层购买按钮，但遇到“支付/确认订单”阶段就立刻停手

它不是绕过平台流程的抢购器，默认设计是“辅助下单，保留最终人工确认”。

## 安装

1. 安装浏览器扩展 `Tampermonkey`
2. 新建脚本
3. 将 [`glm-coding-guard.user.js`](/Users/adolf/Desktop/code/ai-security-platform-main/tools/glm-coding-helper/glm-coding-guard.user.js) 全部粘进去并保存
4. 打开 [GLM Coding 页面](https://www.bigmodel.cn/glm-coding)

## 推荐配置

- 开售时间：`10:00`
- 提前布防：`20` 秒
- 轮询间隔：`400ms`
- 刷新间隔：`2500ms`
- `自动点击首个订阅按钮`：开启
- 最终支付：手动完成

## 使用方式

1. 提前登录 BigModel
2. 提前打开购买页并保持前台
3. 点击脚本面板里的“开始布防”
4. 到点后脚本会轮询按钮状态
5. 如果识别到“立即订阅/购买/抢购”等按钮，会提醒并可自动点第一步
6. 如果页面进入“支付/确认支付/确认订单”等阶段，脚本会自动停止点击

## 可调项

- `目标按钮关键词`
- `售罄文案关键词`
- `停止点击关键词`

如果页面文案改了，只需要在面板里更新这些关键词，不必改代码。

## 风险提示

- 页面结构变化后，脚本可能需要改关键词
- 站点可能有风控、频率限制或活动规则调整
- 本脚本不处理账号登录、验证码、支付确认
- 是否使用自动化能力，仍需你自行评估平台规则与账号风险
