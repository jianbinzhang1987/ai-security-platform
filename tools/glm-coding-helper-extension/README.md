# GLM Coding Guard Chrome 扩展版

这是免油猴版本，适合当前用户脚本注入不稳定的情况。

## 安装

1. 打开 `chrome://extensions/`
2. 确认右上角 `开发者模式` 已开启
3. 点击 `加载未打包的扩展程序`
4. 选择目录：
   `/Users/adolf/Desktop/code/ai-security-platform-main/tools/glm-coding-helper-extension`
5. 打开或刷新 `https://www.bigmodel.cn/glm-coding`

## 成功标志

- 页面右下角出现一个 `GLM` 圆形按钮
- 点击后出现面板
- 面板里可以看到 `开始布防`

## 使用建议

- 提前登录 BigModel
- 到 `09:59:40` 左右打开页面
- 点 `开始布防`
- 保持页面前台
- 抢购成功后在最终支付页手动确认

## 说明

- 该扩展只在 `https://www.bigmodel.cn/glm-coding*` 页面注入
- 只做提醒、页面轮询和首层辅助点击
- 不会替你完成最终支付确认
