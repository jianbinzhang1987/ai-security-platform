# 大模型安全监测平台 - 功能整改清单

**基于文档：** `功能差异梳理-沟通意见.md`
**生成日期：** 2026-04-28

| 序号 | 功能模块     | 发现问题 / 差异描述                                 | 整改处理建议 (基于批注)                                                                  |
| :--- | :----------- | :-------------------------------------------------- | :--------------------------------------------------------------------------------------- |
| 1    |              |                                                     |                                                                                          |
| 2    | 网关统计     | 目前各网关策略统计数据缺失。                        | **暂时删除**此统计功能。                                                           |
| 3    | 身份认证     | 身份认证失败时缺少审计和告警动作。                  | **去掉告警**动作，仅保留基础认证逻辑。                                             |
| 4    | 资源授权     | 资源授权对应的权限动作含义不明确。                  | **调整页面**，明确权限动作定义。                                                   |
| 5    | 资源授权     | 拒绝动作缺少审计和告警。                            | **调整页面**，补充或明确处置逻辑。                                                 |
| 6    | 黑白名单     | 核心模型白名单定义不清晰。                          | **去掉此功能**。                                                                   |
| 7    | 流量治理     | 全局应用调用限流中 QPS 与并发区分不明确，缺少告警。 | **明确定义**：QPS 为应用请求数，并发为用户数。                                     |
| 8    | 流量治理     | 运行趋势统计（待调研 Higress 插件）。               | **暂时去掉**运行趋势展示。                                                         |
| 9    | 流量治理     | 目前不支持排队功能。                                | **暂时去掉**排队相关逻辑。                                                         |
| 10   | 服务熔断     | 触发条件和恢复策略缺失，实现复杂度高。              | **暂时不做**熔断功能。                                                             |
| 11   | 内容安全     | 对接企业自研审核引擎，第三方方案不通用。            | **先屏蔽第三方**对接，优先保证自研引擎。                                           |
| 12   | 会话审计     | 审计概念不明确，不支持关联内容安全策略。            | **简化处理**：作为一种纯粹的日志查询功能，不关联事件，去掉命中策略、网关动作       |
| 13   | 内容安全     | 输入安全、输出安全与提示词攻击的边界定义不清。      | **重新定义**：将提示词攻击作为输入输出检查的一个维度，不单列出来，同时取消会话安全 |
| 14   | 内容策略     | 改写返回配置不合理。                                | **暂时去掉**改写返回功能。                                                         |
| 15   | 提示词攻击   | 阻断、拦截、处置操作关系不明确。                    | **归类处理**：将提示词作为输入输出安全的一项。                                     |
| 16   | 输入安全     | 敏感信息识别不支持采样率。                          | **去掉采样率**配置项。                                                             |
| 17   | 脱敏功能     | 目前为内置模版，不支持自定义。                      | **不允许编辑**，仅展示内置模版。                                                   |
| 18   | 流式检测     | 目前不支持纯实时检测，为分段处理。                  | **去掉**实时检测相关表述或功能。                                                   |
| 19   | 多轮对话检测 | 不支持连续命中阈值功能。                            | **暂时去掉**此功能。                                                               |
| 20   | 会话审计告警 | 告警生成需要 Higress 插件传入额外信息。             | **平台侧补充**相关字段支持。                                                       |
| 21   | 风险关联     | 会话审计与风险事件关联逻辑不清楚。                  | **先不进行关联**处理。                                                             |

---

**说明：** 本清单根据沟通意见汇总，后续开发请以此为准进行功能缩减或逻辑调整。
