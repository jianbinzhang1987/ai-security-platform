# 需求-设计-期次-验收追踪矩阵

## 1. 追踪矩阵说明

本文档建立需求规格与概要设计的映射关系，明确每个期次(P0/P0.5a/P0.5b/P1/P2a/P2b/P3/P4)的交付边界、验收标准和前置依赖，解决分期依赖冲突问题。

**使用方式：**
- 每行对应需求文档中的一个功能点
- 期次列标注实际交付期次
- 验收标准列明确可量化的验收条件
- 依赖列标注前置条件

**P0.5a 最小知识库定义（前置到P0.5a）：**
- 知识条目：仅支持人工录入（无需AI生成），≥50条基础攻击手法和处置预案
- **基础知识提示增强**（非完整RAG）：关键词检索必选+Top3结果注入Prompt，向量可选，**无需安全扫描/可信度元数据/来源引用**（P2a才需完整RAG安全链路）
- 样本库：仅候选集+简单标注，无需评估集/训练集/回归集完整流转
- 相似事件：基于事件特征向量简单匹配，无需复杂关联分析

**P0.5a 验收里程碑：**
1. Prompt注入/越狱检测 FPR/FNR 达到门禁值
2. AI研判可生成摘要，人工可确认/修正/拒绝，修正自动回流
3. 相似事件可关联，低置信研判自动提示人工复核
4. 反馈回流链路打通，样本进入候选集

## 10. 关键依赖总图

```
P0 架构基础
  ↓
P0.5a 核心闭环（Prompt注入/越狱检测/AI研判/相似事件/反馈回流）
  ├─ 依赖：P0架构
  ├─ 依赖：最小知识库（50条基础条目+简单RAG）
  └─ 依赖：最小样本库（候选集+简单标注）
  ↓
P0.5b 检测增强（敏感内容/工具边界/会话追踪）
  ↓
P1 知识库完整版（知识安全防护/样本流转/评测治理/规则优化）
  ├─ 依赖：P0.5a反馈回流
  ├─ 依赖：P0.5a样本库
  └─ 依赖：身份归一/行为基线数据准备
  ↓
P2a 人员与关联分析（用户画像/行为基线/风险累积/知识检索）
  └─ 依赖：P1知识库+身份归一
  ↓
P2b 组织态势与预测（组织风险/趋势/攻击链还原）
  └─ 依赖：P2a分析服务
  ↓
P3 自动响应与报告（L1-L3自动响应/紧急停止/报告生成）
  └─ 依赖：P0.5a研判+P1评测治理
  ↓
P4 智能体运营平台（L1-L3 Agent编排）
  └─ 依赖：P0-P3全部
```

**关键路径：** P0 → P0.5a → P1 → P2a → P3 → P4

## 11. 分期边界澄清

### 11.1 P0.5a 可独立验收的最小集合

**必须交付：**
1. ✅ P0架构（旁路调用/模型网关/熔断降级）
2. ✅ Prompt注入检测 + 越狱检测（FPR/FNR门禁）
3. ✅ AI研判摘要基础版（攻击手法/影响面/判断理由/置信等级）
4. ✅ 人工可确认/修正/拒绝 + 自动回流样本库
5. ✅ 相似事件关联基础版（关键词+简单向量，Top3结果）
6. ✅ 风险事件详情展示（detection_source/ai_status/AI检测结果Tab/AI研判卡片）

**P0.5a 明确不包含（移到P1）：**
- ❌ 完整知识库RAG安全扫描（P0.5a只有简单检索）
- ❌ 知识条目AI生成（P0.5a只有人工录入）
- ❌ 完整样本集流转（P0.5a只有候选集）
- ❌ 评估集冻结机制（P1）
- ❌ 复杂攻击链还原（P2b）
- ❌ 跨应用风险关联（P2a）

### 11.2 P0.5a 最小知识库定义

| 能力 | P0.5a最小版 | P1完整版 | 差异说明 |
|---|---|---|---|
| 知识条目 | 人工录入≥50条 | AI生成+外部导入+人工 | P0.5a无AI生成 |
| 知识审核 | 简单审批 | 入库审核+安全扫描 | P0.5a无安全扫描 |
| RAG检索 | 简单向量相似检索 | 向量+关键词+安全扫描 | P0.5a无关键词混合+无扫描 |
| 检索结果 | Top3简单展示 | 可信度元数据+来源引用 | P0.5a无可信度元数据 |
| 样本库 | 候选集+简单标注 | 5类样本集完整流转 | P0.5a无评估集/训练集/回归集 |

### 11.3 P0.5a 验收检查清单

- [ ] Prompt注入检测：评测集FPR<5%, FNR<10%
- [ ] 越狱攻击识别：评测集FPR<8%, FNR<15%
- [ ] AI研判摘要可生成，包含攻击手法/影响面/判断理由
- [ ] AI研判输出置信等级（high/medium/low）
- [ ] 低置信（<=0.6）研判自动提示"需人工复核"
- [ ] 人工可点击"确认/修正/拒绝"按钮
- [ ] 修正/拒绝操作自动创建样本记录进入候选集
- [ ] 相似事件可展示（至少Top3）
- [ ] 风险事件详情页展示detection_source标签
- [ ] 风险事件详情页展示ai_status状态
- [ ] AI检测结果Tab展示命中片段（引用而非原文）
- [ ] AI研判卡片展示缺失证据/开放问题（如有）
