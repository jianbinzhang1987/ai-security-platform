## 2. 设计原则

- **旁路优先**：所有AI能力采用旁路模式接入，不可用时不影响现有规则引擎和业务主链路
- **渐进改造**：按P0→P0.5a→P0.5b→P1→P1.5→P2a→P2b→P3→P4分期交付，每期可独立验收
- **结构化输出**：AI推理结果必须结构化存储（`ai_inference_record`/`ai_judgement_result`），禁止JSON blob
- **可解释可追溯可覆盖**：AI结果必须包含命中片段引用、判断理由、模型版本、人工可修正
- **数据分级管控**：模型输入按L0-L3分级，L2/L3禁止传外部API，Raw访问必须审批

## 3. 改造前架构

```text
接入采集层 → 数据处理层(规则引擎) → 业务服务层(9服务域) → 存储检索层(5类) → 展示管理层
```

**现有9个服务域：**
1. `asset-service` — 资产管理
2. `monitor-service` — 安全监控
3. `event-service` — 风险事件
4. `policy-service` — 策略中心
5. `auth-service` — 认证授权
6. `audit-service` — 审计服务
7. `session-audit-service` — 会话审计
8. `collector-config-service` — 采集配置
9. `notify-service` — 通知服务

## 4. 改造后架构

    └── AI异步复核（异步深度分析，<30s P99，不阻塞主链路）

    ├── 规则评分（同步产出）
    ├── AI评分异步追加

    ↓
业务服务层（现有9服务域 + 新增4服务域 = 13服务域）
    │
    ├── 现有服务域（9个）：
    │   ├── asset-service          [不变]
    │   ├── monitor-service        [改造：AI检测展示/会话追踪]

## 5. 核心数据流改造

### 5.1 风险识别流（改造后）

```text
标准化数据
→ 规则引擎同步检测（<50ms，产出初始风险评分+风险线索）
→ AI旁路近同步检测（<500ms P99，旁路模式，可降级跳过）
→ AI异步复核（<30s，不阻塞事件创建）
→ 评分融合引擎
    ├── 同步：规则评分 → 创建风险线索
    ├── 异步：AI评分追加 → 若等级上升触发二次告警
    └── 超时：ai_status=timeout，仅取规则评分
→ 风险线索/事件
```

### 5.2 研判闭环流（新增）

```text
风险事件
→ AI研判摘要生成（异步，<30s）
→ 攻击链自动还原（辅助展示）
→ 知识检索辅助（同步RAG）
→ 相似历史事件关联
→ 人工确认/修正/补充
→ 反馈回流样本库
→ 样本支撑规则优化/模型评测
```

### 5.3 处置响应流（改造后）

```text
风险事件
→ AI处置建议（建议性质）
→ 自动响应规则匹配（L1-L4分级）
    ├── L1/L2：可自动执行（规则审批后）
    ├── L3：可自动（需白名单+熔断）
    └── L4：不可自动，必须人工审批+MFA
→ 动作执行（带TTL自动恢复）
→ 审计留痕
```

## 6. 改造边界约束

| 约束 | 说明 |
|---|---|
| 规则引擎不可降级 | 同步硬规则是基线，AI旁路不可覆盖或跳过 |
| AI旁路模式 | AI检测不可用时，规则引擎正常运行 |
| 异步不阻塞 | AI异步复核结果通过事件更新接口追加，不阻塞事件创建 |
| 结构化存储 | AI推理结果写入`ai_inference_record`/`ai_judgement_result`，禁止JSON blob |
| 数据分级 | 模型输入按L0-L3分级，L2/L3禁止传外部API |
| 成本限额 | 每条Span AI检测Token上限、月度预算告警、限流后仅规则引擎运行 |

```text
P0（基础架构先行）
├── 大模型旁路调用架构 + 模型网关(ai-model-service骨架)
├── model_call_log审计日志
├── 脱敏框架 + 数据分级
├── 评分融合引擎骨架（规则优先+AI异步追加）
├── 熔断器 + 降级策略
└── 最小评测集框架

P0.5a（核心闭环最小可验收单元）
├── Prompt注入+越狱检测接入融合引擎
├── AI研判摘要+反馈回流
└── 风险事件详情：detection_source + ai_status + AI检测结果Tab

P0.5b（策略配置与展示增强）
├── 内容安全策略AI检测配置Tab
├── 高级规则项AI增强实现方式
├── 会话风险追踪页
└── 安全总览AI检测来源统计

P1（知识库与评测治理）
├── knowledge-service（知识库+RAG+样本库）
├── 模型治理：评测集、版本对比、上线门禁
├── 高级SOC前置：身份归一、行为基线数据准备
└── AI规则优化建议

P1.5（知识库增强）
├── 策略模板库
└── 安全知识问答

P2a（高级SOC — 人员与关联）
├── analysis-service（人员风险/关联分析/行为基线）
├── 知识检索辅助研判
└── 安全总览增强视图(3个)

P2b（高级SOC — 组织态势与预测）
├── 组织风险态势+时序趋势
├── 攻击链自动还原
└── 安全总览增强视图(2个)

P3（受限自动响应与报告自动化）
├── AI处置建议+自动响应(L1-L3)
├── 安全报告自动生成
└── 策略效果评估报告

P4（智能体运营平台）
├── agent-service（L2/L3 Agent编排）
├── 智能体管理平台
└── 策略模板库完善
```
