# 网关策略管理 — 原型图功能审核报告

网关策略管理共包含 5 个子功能页面：

1. **访问控制策略** (`access-control.html`)
2. **流量与服务治理** (`traffic-governance.html`)
3. **内容安全策略** (`content-security.html`)
4. **会话审计策略** (`session-audit.html`)
5. **绑定与下发** (`gateway-distribution.html`)

---

## 一、各页面功能现状

### 1. 访问控制策略

**整体布局：** 统计卡片（4项）→ 筛选栏 → 三 Tab 表格（身份认证 / 资源授权 / 黑白名单）

| 子模块   | 表格核心列                                   | 行内操作              |
| -------- | -------------------------------------------- | --------------------- |
| 身份认证 | 认证方式、作用范围、校验规则、失败动作、状态 | 编辑、查看日志 / 下发 |
| 资源授权 | 授权主体、资源范围、权限动作、拒绝动作、状态 | 编辑、版本 / 下发     |
| 黑白名单 | 名单模式、匹配维度、名单内容、命中动作、状态 | 编辑、命中记录 / 停用 |

---

### 2. 流量与服务治理

**整体布局：** 统计卡片（4项）→ 筛选栏 → 两 Tab 表格（访问限流 / 服务熔断）

| 子模块   | 特色列                                                    | 行内操作                  |
| -------- | --------------------------------------------------------- | ------------------------- |
| 访问限流 | 限流维度、阈值配置标签、超限动作                          | 编辑、命中记录 / 下发     |
| 服务熔断 | 触发条件、恢复策略、当前状态（熔断中/正常）、最近触发时间 | 编辑、手动解除 / 查看趋势 |

---

### 3. 内容安全策略

**整体布局：** 统计卡片（4项）→ 筛选栏 → 四 Tab 表格（提示词攻击 / 输入安全 / 输出安全 / 会话安全）

顶部按钮：样例模拟、敏感词库、新建内容策略

---

### 4. 会话审计策略

**整体布局：** 统计卡片（4项）→ 筛选栏 → 三 Tab 表格（审计范围 / 镜像转发 / 留存与脱敏）

顶部按钮：刷新转发状态、新建审计策略

---

### 5. 绑定与下发

**整体布局：** 统计卡片（4项）→ 筛选栏 → 单一平铺表格（含进度条下发状态）

顶部按钮：刷新下发回执、查看下发历史、新建绑定

---

## 二、问题清单（按严重程度分级）

### 🔴 严重缺失 — 业务逻辑无法闭环

| #   | 问题描述                                                             | 涉及页面                                             | 说明                                                                                                                                     |
| --- | -------------------------------------------------------------------- | ---------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| S-1 | **全部页面无删除操作**                                         | 所有 5 个页面                                        | 行内操作列和批量操作区均无"删除"按钮，策略生命周期管理无法闭环                                                                           |
| S-2 | **新建/编辑弹窗字段固定，不随策略类型动态联动**                | access-control、content-security、traffic-governance | 选择"身份认证"和"黑白名单"所需字段完全不同，固定表单无法完整收集各类型策略配置，实现时必须拆分                                           |
| S-3 | **内容安全弹窗无法区分四个安全域的差异化配置**                 | content-security                                     | 提示词攻击需"规则包/模型"，输入安全需"审核服务+采样率"，输出安全需"敏感词库+脱敏模板"，会话安全需"词库+检测方向"，通用弹窗完全无法表达   |
| S-4 | **会话审计三 Tab 共用同一弹窗，实体不同却共享字段**            | session-audit                                        | 审计范围（策略）、镜像转发（转发配置）、留存与脱敏（留存规则）是三类不同实体，统一弹窗导致保存逻辑混乱；"留存与脱敏"Tab 也无独立新建入口 |
| S-5 | **绑定与下发弹窗"绑定对象"为纯文本输入，无策略联动**           | gateway-distribution                                 | 选择策略类型后应联动展示可绑定的策略列表和路由对象，纯文本输入无法保证数据一致性，实际无法与后端关联                                     |
| S-6 | **策略无版本管理/发布流程**                                    | content-security、session-audit                      | 编辑后直接保存即生效，缺少草稿 → 审核 → 发布 → 版本号递增的完整流程；而绑定页展示了版本号，两侧设计逻辑脱节                           |
| S-7 | **访问控制"黑白名单"弹窗缺少 IP/CIDR 列表编辑区**              | access-control                                       | 仅有匹配方式下拉，无录入 IP 段的字段，核心功能残缺                                                                                       |
| S-8 | **流量治理弹窗缺少阈值数值字段（限流）和触发参数字段（熔断）** | traffic-governance                                   | 限流缺 QPS/并发/日配额数值输入；熔断缺错误率阈值、窗口期、恢复时间等结构化字段                                                           |

## 三、优先修复建议

**第一优先级（阻塞原型走查）：**

- 修复弹窗动态表单，按策略类型渲染差异化字段（S-2、S-3、S-4）
- 补充删除操作（S-1）
- 补充"黑白名单"、"限流"、"熔断"弹窗的核心配置字段（S-7、S-8）

**第二优先级（功能闭环）：**

- 添加分页控件（M-1）
- 添加批量操作区域（M-2）
- 关键二次确认弹窗：下发、手动解除熔断（M-10、M-11）
- 关键跳转页面：下发历史、命中记录、失败节点（M-8、M-9）

**第三优先级（体验打磨）：**

- 行内状态快捷开关（M-3）
- 统计卡片下钻、时间范围切换（L-8、L-9）
- 策略优先级字段（L-11）
- 空状态设计（L-13）

---

总体来看，网关策略管理模块的**信息架构和导航结构是清晰的**，5 个子页面的功能划分合理，统计卡片 + 筛选 + Tab 分组的布局模式也符合安全管理平台的常规范式。主要的不完善集中在两个层面：**弹窗表单的动态化不足**（各类型策略配置差异显著，通用表单无法承载）和**全局性的表格基础功能缺失**（分页、批量操作、删除、状态切换开关）。建议优先解决这两类问题后再进行下一轮走查。
