# 核心字段字典

## 1. 文档目标

本文档用于统一大模型安全监测平台核心字段命名、中文含义、适用对象和引用关系，作为接口 DTO、数据库表结构和前端字段展示的共同依据。

---

## 2. 通用字段

| 字段名 | 中文含义 | 适用对象 | 说明 |
|---|---|---|---|
| `created_at` | 创建时间 | 全部核心对象 | 记录对象创建时间 |
| `updated_at` | 更新时间 | 全部核心对象 | 记录最近更新时间 |
| `created_by` | 创建人 | 配置类、事件类对象 | 保存用户 ID |
| `updated_by` | 更新人 | 配置类对象 | 保存用户 ID |
| `request_id` | 请求 ID | 所有接口 | 用于链路追踪 |
| `idempotency_key` | 幂等键 | 写接口 | 防止重复提交 |
| `approval_id` | 审批单 ID | 高危操作 | 关联审批单 |
| `reason` | 操作原因 | 状态变更、审批、回滚 | 必填场景由接口定义 |

## 3. 资产字段

| 字段名 | 中文含义 | 适用对象 | 说明 |
|---|---|---|---|
| `app_id` | 应用 ID | 应用、事件、Trace、策略绑定 | 应用全局唯一标识 |
| `app_name` | 应用名称 | 应用 | 展示名称 |
| `business_line` | 业务线 | 应用 | 建议统一使用该字段，不再使用 `biz_line` |
| `owner_id` | 负责人 ID | 应用、事件 | 关联用户 |
| `env` | 环境 | 应用、策略绑定 | 如生产、测试、预发 |
| `access_status` | 接入状态 | 应用 | 引用全局状态模型 |
| `health_status` | 健康状态 | 应用 | 表示采集、配置、策略同步综合健康 |
| `instance_id` | 应用实例 ID | 应用实例、运行生效状态 | 实例唯一标识 |
| `instance_status` | 实例状态 | 应用实例、Collector | 引用全局状态模型 |
| `sync_status` | 同步状态 | 应用实例、Collector 配置同步 | 表示配置或策略同步状态 |
| `node_id` | Agent / 节点 ID | Agent / 节点、事件 | 节点唯一标识 |
| `identify_status` | 识别状态 | Agent / 节点 | 引用全局状态模型 |
| `confidence_level` | 置信等级 | Agent / 节点 | 如强识别、中识别、弱识别 |
| `tool_id` | 工具 ID | 工具、事件 | 工具唯一标识 |
| `resource_id` | 资源 ID | 资源、事件、证据 | 数据库、知识库、API 等资源标识 |

## 4. 监控与证据字段

| 字段名 | 中文含义 | 适用对象 | 说明 |
|---|---|---|---|
| `session_id` | 会话 ID | 会话、Trace、事件上下文 | 多轮会话唯一标识 |
| `trace_id` | Trace ID | Trace、Span、事件、审计 | 调查链路主标识 |
| `span_id` | Span ID | Span、事件、证据关系 | 最小证据锚点 |
| `parent_span_id` | 父 Span ID | Span | 用于还原调用链 |
| `risk_stage` | 风险阶段 | Span、证据、事件 | 意图输入、工具调用、输出结果等 |
| `risk_type` | 风险类型 | 线索、事件、规则 | Prompt 注入、工具越界、敏感输出等 |
| `risk_level` | 风险等级 | 线索、事件、Trace | 高、中、低等 |
| `source_field` | 证据来源字段 | Span、事件证据关系 | 如 prompt、response、tool_input |
| `evidence_offset` | 证据位置偏移 | Span、事件证据关系 | 标识命中内容在原文中的位置 |
| `raw_ref` | 原始载荷引用 | Span、Raw 证据 | 不直接保存 Raw 内容 |
| `payload_hash` | 载荷哈希 | Raw 证据 | 用于完整性校验 |
| `mask_status` | 脱敏状态 | Span、证据接口 | 表示已脱敏、未脱敏、不可见等 |
| `raw_access_required` | 是否需要 Raw 授权 | 证据引用 | 控制高敏访问 |

## 5. 风险事件与处置字段

| 字段名 | 中文含义 | 适用对象 | 说明 |
|---|---|---|---|
| `clue_id` | 风险线索 ID | 风险线索、事件证据关系 | 事件生成前的识别结果 |
| `clue_status` | 线索状态 | 风险线索 | 引用全局状态模型 |
| `event_id` | 风险事件 ID | 风险事件、动作、审计 | 正式闭环主档 ID |
| `event_status` | 事件状态 | 风险事件 | 引用全局状态模型 |
| `action_id` | 处置动作 ID | 处置动作、响应记录 | 动作级台账 ID |
| `action_type` | 动作类型 | 处置动作 | 通知、限制、降级、恢复、回滚等 |
| `action_scope` | 动作范围 | 处置动作 | Session、Tool、Agent、App 等 |
| `target_type` | 目标对象类型 | 处置动作、绑定、下发 | 应用、工具、实例、路由等 |
| `target_id` | 目标对象 ID | 处置动作、绑定、下发 | 与 `target_type` 配合使用 |
| `ttl` | 生效时长 | 处置动作 | TTL 型限制动作必填 |
| `action_status` | 动作状态 | 处置动作 | 引用全局状态模型 |
| `rollback_status` | 回滚状态 | 处置动作 | 与动作执行状态分离 |
| `impact_desc` | 影响说明 | 处置动作、审批 | 描述影响范围和风险 |
| `rollback_plan` | 回滚方案 | 处置动作、策略发布 | 高危动作建议必填 |

## 8. 命名收敛要求

以下旧字段或模糊字段不建议继续使用：

| 不建议使用 | 建议替代 |
|---|---|
| `status` | 使用具体状态字段，如 `event_status`、`policy_status` |
| `biz_line` | `business_line` |
| `collector_health` | `health_status` |
| `heartbeat_status` | `instance_status` |
| `dispatch_id` | `deployment_id` |
| `dispatch_task` | `deployment` |
| `gateway_policy` | `policy` + `policy_type` |
| `probe_rule` | `rule` + `rule_type` |
| `offset` | `evidence_offset` |
| `masking_status` | `mask_status` |
| `rollbacked` | `rolled_back` |

---

## 9. 后续使用要求

1. 接口设计文档应优先引用本文字段名。
2. 数据库详细设计可在本文字段基础上增加物理字段。
3. 前端展示可以使用中文文案，但不得把中文状态作为接口枚举。
4. 新增核心对象字段前，应先检查本文是否已有等价字段。
