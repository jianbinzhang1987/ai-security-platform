# 安全可观测性设计概念规范

**文档编号**：AGENTSEC-SEC-OBS-CONCEPT-v1.1
**版本**：v1.1 | **日期**：2026-04-16 | **状态**：评审中

---

## 1. 文档目的

定义大模型安全监测平台的**安全可观测性**核心设计概念。区别于通用LLM可观测性（关注延迟、Token、成本），安全可观测性关注：智能体运行中是否存在安全风险、风险是否正在发生、风险如何演变、证据如何定位。

本平台主要面向企业内网与私有化客户，产品侧统一使用"风险、合规、异常、越界、证据、处置、能力边界、风险链路、风险溯源"等表达。本文保留必要技术术语，但页面、报告和菜单命名优先采用合规与风险治理口径。

每个概念包含：定义、数据来源、计算逻辑、可视化形态、交互方式、MVP边界。

## 3. C1 — 安全态势评分

### 3.1 定义

为每个`app_id`计算0-100安全健康度。100=无风险，0=极高风险。类似"信用分"。

### 3.2 评分维度

| 维度 | 权重 | 来源 | 计算 |
|---|---|---|---|
| 高危事件密度 | 30% | risk_events | 近24h高危事件数/总Span数×系数 |
| 阻断率 | 20% | spans(status=blocked) | blocked数/总Span数 |
| 误报率 | 10% | risk_events(status=false_positive) | 误报数/已处置事件数 |
| 策略覆盖度 | 15% | 策略配置表 | 已生效规则/应覆盖规则 |
| 行为异常分 | 15% | 行为序列引擎 | 异常Span占比 |
| 采集健康度 | 10% | Collector指标 | 心跳在线率+上报完整率 |

### 3.3 算法（MVP简化版）

```
score = 100
  - min(high_risk_density × 300, 30)
  - min(block_rate × 200, 20)
  - min(fp_rate × 50, 10)
  - (1 - policy_coverage) × 15
  - min(anomaly_score × 150, 15)
  - (1 - collection_health) × 10
```

| 区间 | 等级 | 颜色 | 含义 |
|---|---|---|---|
| 90-100 | A | 绿 | 安全良好 |
| 70-89 | B | 蓝 | 低风险需关注 |
| 50-69 | C | 橙 | 中风险需处置 |
| 0-49 | D | 红 | 高风险立即响应 |

### 3.4 可视化

- **大盘**：大号数字+等级字母+颜色+趋势箭头
- **应用详情**：半圆仪表盘+分维度扣分明细条形图
- **应用列表**：评分列，支持排序

### 3.5 交互

- 点击评分→展开分维度扣分明细
- 点击某维度→下钻到对应Span/事件列表
- D级应用→一键跳转应用详情>安全画像

### 3.6 MVP边界

- P0 只展示基础安全指标卡、未处置事件、阻断次数、采集健康和风险趋势
- P1 引入正式加权评分，不引入ML模型
- 每小时刷新，不做实时计算
- 不做跨应用对比排名（P2）

## 4. C2 — 风险向量雷达图

### 4.1 定义

5轴雷达图展示5个风险向量的风险程度，一眼看清当前风险分布。

### 4.2 五个风险向量

| 向量 | 数据来源 | 量化 |
|---|---|---|
| Prompt注入 | risk_type IN (prompt_injection, jailbreak) | 近24h事件数归一化0-100 |
| 工具越权 | risk_type IN (tool_abuse, permission_violation) | 同上 |
| 数据泄露 | risk_type IN (pii_leak, credential_exposure, data_exfiltration) | 同上 |
| 意图偏离 | risk_type = intent_deviation + 意图对齐评分异常 | 同上 |
| 行为异常 | risk_type IN (behavior_anomaly, sequence_anomaly) | 同上 |

### 4.3 可视化

- 5轴雷达图，每轴0-100
- 填充区域=当前风险程度，面积越大=风险越高
- 外圈虚线=基线（近30天均值），内圈实线=当前值
- 当前值超基线的轴用红色标注

### 4.4 交互

- 悬停某轴→显示该向量具体事件数和Top3风险Span
- 点击某轴→下钻到观测工作台，自动过滤该风险类型
- 切换时间范围→24h/7d/30d

### 4.5 MVP边界

- 5个固定向量，不支持自定义
- 简单归一化，不做趋势预测
- 基线用近30天均值，不做动态建模

## 5. C3 — 安全证据面板

### 5.1 定义

点击任意Span或事件时从右侧滑出的统一调查面板，展示所有安全相关信息。是安全运营的核心UI组件。

### 5.2 面板结构（4个折叠区域）

**区域1：基础身份**

span_id（可复制）、trace_id（可跳转）、session_id（可跳转）、app_id（可跳转）、span_kind、时间+时长、status（颜色区分）

**区域2：内容证据**（按span_kind展示不同内容）

| span_kind | 展示 |
|---|---|
| llm | Prompt原文（脱敏）、Response原文、model、token_count |
| tool | 工具名、Tool Input/Output原文、执行时长 |
| retriever | 查询内容、返回文档摘要 |
| guardrail | 触发规则名、匹配内容、触发动作 |

所有原文：按策略脱敏、超2000字符截断+展开、检测匹配片段红色高亮

**区域3：安全证据**

风险等级、风险类型、置信度、检测规则名+匹配片段、阻断动作+原因、意图对齐评分（可选）、行为偏离度（可选）

**区域4：关联导航**

| 方向 | 目标 |
|---|---|
| 上跳 | trace_id→Trace视图、session_id→Session视图、app_id→应用详情 |
| 下跳 | parent_span_id→父Span面板、子Span列表 |
| 横跳 | 同risk_type Span、同tool_name Span、关联risk_event |

### 5.3 交互

- 右侧滑出，宽度40%
- Esc关闭、↑↓切换Span
- 内容区支持Ctrl+F搜索

### 5.4 MVP边界

- 区域1-3必须实现，区域4横跳P1
- 意图对齐/行为偏离引擎未就绪时隐藏
- 全文搜索P1

## 6. C4 — 风险链路高亮

### 6.1 定义

Trace 风险剧本视图上自动识别并高亮典型风险路径，用视觉连接线串联"风险入口→中间传递→最终影响"。

### 6.2 风险链路模式库

| 模式 | 入口Span | 中间Span | 影响Span |
|---|---|---|---|
| 注入→越权 | LLM(注入) | Tool(越权) | Tool(敏感操作) |
| 注入→异常流出 | LLM(注入) | Tool(数据读取) | Tool(网络发送) |
| 渐进式注入 | LLM(低风险) | LLM(中风险) | LLM(高风险) |
| 凭证异常获取 | LLM(诱导输出) | Tool(凭证访问) | Tool(异常流出) |

### 6.3 可视化

- 风险链路Span红色边框或醒目标识
- Span间红色虚线箭头，标注风险阶段
- 视图上方摘要条："检测到1条风险链路：注入→越权→异常流出，涉及3个Span"

### 6.4 交互

- 点击摘要条→自动滚动到入口Span
- 点击红色箭头→展开阶段分析
- "仅看风险链路"→过滤非风险链路Span

### 6.5 MVP边界

- 4种预定义模式，不支持自定义
- 仅Trace内检测，不跨Session（P2）
- 服务端检测，前端仅展示

## 7. C5 — MCP权限边界图

### 7.1 定义

对比Agent声明的MCP工具/资源权限与实际调用范围，越界部分高亮。

### 7.2 数据来源

- 声明权限：应用详情>工具与资源声明（人工配置或SDK上报）
- 实际调用：Span数据中tool_name+tool_input聚合

### 7.3 可视化

每个工具一张卡片：
- ✅ 声明允许+实际在范围内
- ⚠️ 实际调用超出声明范围（越界）
- ❌ 声明允许但未使用
- 🔴 声明禁止但仍有调用（严重越界）

底部汇总：越界工具数、越界调用数、风险等级

### 7.4 交互

- 点击越界卡片→展开越界Span列表→打开安全证据面板
- "导出越界报告"

### 7.5 MVP边界

- 依赖人工配置声明权限
- 仅工具级越界，不展示参数级/资源级（P2）

## 8. C6 — 工具调用安全矩阵

### 8.1 定义

"工具×风险类型"交叉统计热力图，快速定位哪个工具在哪种风险上出问题最多。

### 8.2 可视化

```
              Prompt注入  工具越权  数据泄露  意图偏离  行为异常
  搜索工具       2        0        1        0        3
  发送消息       0        5        3        1        0    ← 高风险
  文件读取       1        2        0        0        1
  数据库查询     0        1        2        0        0
```

- 单元格热力图：0=白、1-3=浅黄、4-10=橙、10+=红
- 行/列汇总可排序

### 8.3 交互

- 点击单元格→展开该"工具×风险类型"Span列表
- 行头/列头点击→展开该工具/风险类型所有Span

### 8.4 MVP边界

- 仅近24h数据，不支持自定义时间范围
- 固定5类风险类型
- 不做趋势对比（P2）

## 9. C7 — 跨轮风险演变时间线

### 9.1 定义

Session视图内展示风险评分随交互轮次的变化趋势，标注风险转折点。

### 9.2 可视化

```
风险评分
  100│          ●
   60│        ╱   ●─────┐  ← 转折点
   40│      ╱          ●  ●
   20│    ●
    0│  ╱
      └──┬──┬──┬──┬──┬──┬──┬──→ 轮次
         1  2  3  4  5  6  7

  轮次3: 首次注入(low)  轮次5: 工具越权(high) ←转折
  轮次6: 数据异常流出(critical)
```

- X轴=轮次，Y轴=风险评分，折线图
- 转折点红色圆点+标注框
- 下方色带：绿(正常)→黄(试探)→橙(传递)→红(影响)

### 9.3 交互

- 悬停转折点→展示风险事件摘要
- 点击转折点→展开该轮次Trace+安全证据面板
- "导出风险时间线"

### 9.4 MVP边界

- 仅在有稳定session_id时启用
- 转折点用简单阈值（评分跳变>20），不做复杂模式识别
- 不做跨Session关联（P2）

## 10. C8 — 监控覆盖度与盲点面板

### 10.1 定义

展示平台当前"看得到什么、可能看不到什么"。安全可观测性不仅要展示已发现风险，也要展示采集、检测、声明和处置链路中的盲点。

### 10.2 覆盖度维度

| 维度 | 指标 | 用途 |
|---|---|---|
| 采集覆盖度 | 已接入 Agent / 应接入 Agent、活跃实例、SDK 版本覆盖率 | 发现未接入或版本滞后的盲区 |
| Trace 完整度 | Trace 断链率、无 parent_span_id 比例、黑盒工具调用数 | 判断证据链是否完整 |
| 工具声明覆盖度 | 已观测未声明工具数、未声明工具调用占比 | 发现影子工具和权限声明缺口 |
| 检测覆盖度 | 已启用规则数、规则激活率、长期零触发检测类型 | 发现检测规则空白或采集缺失 |
| 处置覆盖度 | 未处置事件、超时事件、无责任人事件 | 发现运营闭环缺口 |

### 10.3 可视化

- 大盘底部小组件：接入覆盖、Trace 完整度、影子工具、规则激活率
- 报告中心：按周/月展示覆盖度趋势和风险盲点变化
- 应用详情：展示该应用的 SDK 版本、断链 Trace、工具声明缺口

### 10.4 MVP边界

- P0 展示采集健康、Trace 断链、影子工具数量、规则激活率
- P1 增加按应用 / Agent / 工具维度的覆盖度下钻
- P2 增加自动盲点解释和修复建议

## 11. C9 — 数据流安全视图

### 11.1 定义

展示敏感数据从 Prompt / RAG / Tool Output 进入系统，到 LLM Response / Tool Input / 外部 API 输出的流转路径，用于支撑内网客户的数据安全与合规审计。

### 11.2 数据流事件类型

| 类型 | 说明 |
|---|---|
| 输入侧敏感数据 | Prompt / RAG 文档中出现手机号、邮箱、身份证、凭证、内部代码等 |
| 传递侧敏感数据 | LLM Response 中的敏感数据被传递给 Tool Input |
| 外传侧敏感数据 | Tool 将敏感数据发送到外部 API、邮件、IM、文件导出等通道 |
| 缓存侧敏感数据 | 敏感数据进入 Session 上下文、缓存、日志或持久化存储 |

### 11.3 可视化

- Span 详情：展示 `security.pii.detected`、`security.pii.types`、`security.pii.action`
- Trace 视图：在风险剧本中标注敏感数据出现、传递和输出节点
- 事件详情：展示敏感数据类型、脱敏状态、处置动作和证据片段
- 大盘 / 报告：展示今日 PII 事件、凭证泄露事件、数据异常流出风险趋势

### 11.4 MVP边界

- P1 支持 PII 类型统计、脱敏状态、Tool Input / Output 中敏感数据标注
- P2 支持跨 Span 数据流路径自动串联和异常流出影响评估

## 13. 安全可观测性 vs 通用可观测性维度对照

| 维度 | 通用视角（参考资料已有） | 安全视角（本规范补充） |
|---|---|---|
| Trace | 调用链完整性、延迟、错误率 | 风险链路还原、风险Span标注、风险路径高亮 |
| Span | 耗时、状态码、属性标签 | 安全证据单元：风险评分、规则匹配、阻断原因 |
| Session | 多轮上下文、Token累计 | 跨轮风险演变、渐进注入、风险升级趋势 |
| LLM调用 | 模型、Token、延迟、成本 | 注入检测、越狱匹配、输出毒性/PII扫描 |
| Tool调用 | 工具名、耗时、成功率 | 越权检测、参数危险模式、权限边界违规 |
| MCP | 无 | 权限审计、声明vs实际对比、跨工具风险路径 |
| Agent行为 | 调用频率、工具组合统计 | 基线偏离、意图对齐、任务偏离、异常序列 |
| 数据流 | 无或仅日志检索 | PII/凭证从输入到工具输出的流转路径、脱敏状态、异常流出风险 |
| 覆盖度 | 服务可用性、Agent 在线率 | 未接入 Agent、Trace 断链、黑盒工具、规则空白、影子工具 |
| 大盘 | QPS、P99、Token消耗 | 基础风险指标、态势评分、风险向量分布、高风险排行、覆盖度 |
