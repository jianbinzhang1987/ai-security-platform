# 事件详情页（event-detail.html）交互改造方案

## 一、改造目标

将当前"数据模型字段的UI堆砌版"改造为"以处置工作流为中心"的事件详情页，使运营人员在3秒内判断"这是什么风险、AI可不可信、我该做什么"。

---

## 二、当前问题清单

### 2.1 首屏信息过载
- 副标题包含 `trace_id` / `span_id` / `risk_stage`，开发态术语直接暴露
- 4个状态标签并列（detectionSourceTag / aiStatusTag / aiAnalysisStatusTag / confidenceReviewTag），15种组合让用户困惑

### 2.2 事件概况字段过多
- 17个字段平铺展示，核心信息被淹没
- `AI检测状态` `AI研判状态` 等枚举值直接暴露给运营人员

### 2.3 证据与结论物理拆散
- 证据在左侧"证据工作区→AI检测结果Tab"内
- AI研判结论在右侧"AI辅助研判卡片"中
- 用户必须左右跳跃阅读

### 2.4 三套操作区无流程引导
- AI研判卡片（确认/修正/拒绝）
- AI处置建议卡片（采纳并执行/修改后执行/拒绝并记录/转人工）——**P3能力，不应在P0.5a出现**
- 处置动作卡片（指派/下发限制/标记误报/接受风险/处置登记）

### 2.5 P3能力混入P0.5a
- 自动执行台账（L1/L2/L3动作级别、TTL倒计时）
- AI处置建议卡片（推荐动作、动作级别、TTL、影响评估）
- 动作与审批台账（`action_id` / `approval_id` / `rollback_status`）

### 3.2 AI辅助可信度徽章规范

| 状态组合 | 徽章样式 | 文案 | tooltip |
|---------|---------|------|---------|
| AI检测=success + 置信度高 | 🟢 绿色 + ✓ | AI辅助可信 | AI分析已完成，结论可信 |
| AI检测=success + 置信度低 | 🟡 黄色 + ? | AI辅助待确认 | AI分析已完成，置信度较低，建议人工复核 |
| AI检测=success + 未人工确认 | 🟡 黄色 + ? | AI辅助待确认 | AI辅助分析已生成，等待人工确认 |
| AI检测=timeout / error | ⚪ 灰色 + — | AI辅助不可用 | AI辅助当前不可用，已自动切换至规则检测 |
| AI检测=circuit_open | ⚪ 灰色 + — | AI辅助不可用 | AI服务熔断中，已自动切换至规则检测 |
| AI检测=skipped_by_policy | ⚪ 灰色 + / | AI辅助未启用 | 本事件按策略配置跳过AI检测 |

- 运营人员**永远看不到** `success`/`timeout`/`circuit_open`/`skipped` 等原始枚举值
- 点击徽章展开面板，展示原始技术状态（仅对管理员可见）

## 五、JavaScript逻辑调整

### 5.1 AI可信度徽章计算

```javascript
function getAiTrustBadge(ai) {
  var status = ai.aiStatus;
  var confidence = ai.confidenceLevel;
  var analysisStatus = ai.analysisStatus;
  
  // 降级状态
  if (['timeout', 'error', 'circuit_open'].indexOf(status) >= 0) {
    return { class: 'trust-unavailable', icon: '—', text: 'AI辅助不可用', hint: 'AI辅助当前不可用，已自动切换至规则检测' };
  }
  if (status === 'skipped_by_policy' || status === 'not_configured') {
    return { class: 'trust-unavailable', icon: '/', text: 'AI辅助未启用', hint: '本事件按策略配置跳过AI检测' };
  }
  
  // 正常状态
  if (confidence === 'low') {
    return { class: 'trust-pending', icon: '?', text: 'AI辅助待确认', hint: 'AI分析已完成，置信度较低，建议人工复核' };
  }
  if (analysisStatus === 'generated' && confidence !== 'low') {
    return { class: 'trust-pending', icon: '?', text: 'AI辅助待确认', hint: 'AI辅助分析已生成，等待人工确认' };
  }
  
  return { class: 'trust-reliable', icon: '✓', text: 'AI辅助可信', hint: 'AI分析已完成，结论可信' };
}
```

### 5.2 处置决策交互

```javascript
function selectDecision(type) {
  // 收起所有选项的详细区域
  document.querySelectorAll('.decision-body').forEach(function(el) { el.style.display = 'none'; });
  document.querySelectorAll('.decision-option').forEach(function(el) { el.classList.remove('selected'); });
  
  // 展开当前选项
  var map = { confirm: 'confirmActions', falsePositive: 'fpActions', acceptRisk: 'acceptActions' };
  var bodyId = map[type];
  if (bodyId) {
    document.getElementById(bodyId).style.display = 'block';
    document.getElementById(bodyId).closest('.decision-option').classList.add('selected');
  }
  
  // 自动提交AI反馈
  var feedbackMap = { confirm: 'confirmed', falsePositive: 'rejected', acceptRisk: 'rejected' };
  if (feedbackMap[type]) {
    // 静默提交AI反馈，无需弹窗提示
    submitAiFeedbackSilent(feedbackMap[type]);
  }
}
```

## 六、验收检查项

- [ ] 首屏无 `trace_id` / `span_id` / `model_version` 等术语
- [ ] 运营人员看不到 `success` / `timeout` / `circuit_open` / `skipped` 原始枚举值
- [ ] 事件概况字段 ≤ 6 个
- [ ] 证据与AI研判在同一视觉区块内（无需左右跳跃）
- [ ] 操作区仅有一组"三选一"决策按钮（确认风险/标记误报/接受风险）
- [ ] 无"AI处置建议"独立操作卡片
- [ ] 无"自动执行台账"
- [ ] 点击"标记误报"自动触发AI反馈，无需单独点击"拒绝研判"
- [ ] timeout/circuit_open/error 事件有明确的降级提示（"AI辅助不可用"徽章 + 说明文案）
