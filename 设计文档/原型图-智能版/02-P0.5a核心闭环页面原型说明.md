# P0.5a 核心闭环页面原型说明

## 1. 目标

P0.5a 原型聚焦“AI 检测 + AI 研判 + 人工反馈 + 样本回流”的最小闭环。

设计目标不是展示完整智能化平台能力，而是证明安全运营人员可以在风险事件详情页完成以下工作：

1. 看到该事件由规则、AI 或规则+AI 联合检出。
2. 理解 AI 为什么判定有风险，包括命中片段、判断理由、反例提示和模型版本。
3. 查看 AI 研判摘要，包括攻击手法、影响面、处置优先级、置信等级、不确定性。
4. 对 AI 结果执行确认、修正或拒绝。
5. 反馈结果自动进入样本候选集，形成后续评测和优化基础。

## 2. 核心用户

| 用户 | 主要诉求 |
| --- | --- |
| 安全运营人员 | 快速判断事件是否真实、严重程度和下一步处理建议 |
| 安全管理员 | 确认 AI 输出是否可信，保障反馈和审计链路完整 |
| 策略运营人员 | 从误报、命中、边界样本中发现规则和模型优化方向 |

## 3. 核心流程

```text
风险事件生成
  -> 规则检测同步命中
  -> AI 检测旁路执行
  -> 评分融合生成 detection_source 与 ai_status
  -> AI 研判任务生成摘要
  -> 风险事件详情页展示 AI 检测结果与 AI 研判卡片
  -> 人工确认 / 修正 / 拒绝
  -> 反馈进入样本候选集
  -> 审计日志记录操作
```

## 4. 页面一：风险事件详情

### 4.1 页面定位

风险事件详情是 P0.5a 的核心页面。它承载 AI 检测结果解释、AI 研判摘要、人工反馈和样本回流入口。

建议基于现有文件改造：

```text
pages/events/event-detail.html
```

### 4.2 页面结构

```text
页面标题区
  事件标题 / 风险等级 / 事件状态 / 检测来源 / AI状态

顶部概览区
  基础信息
  风险评分
  检测来源分布
  AI研判状态

主体工作区
  左侧：证据与检测结果
    Tab 1 事件概况
    Tab 2 证据链
    Tab 3 AI检测结果 [新增]
    Tab 4 处置记录
    Tab 5 审批台账

  右侧：AI辅助研判侧栏
    AI研判卡片 [新增]
    相似事件 [新增]
    反馈操作 [新增]
```

### 4.3 标题区新增信息

| 字段 | 展示方式 | 说明 |
| --- | --- | --- |
| detection_source | 标签 | rule / ai_model / rule_and_ai |
| ai_status | 状态标签 | not_configured / pending / success / timeout / error / circuit_open / skipped_by_policy |
| ai_analysis_status | 状态标签 | pending / generated / timeout / error / circuit_open / skipped / confirmed / modified / rejected |
| low_confidence | 提醒标识 | 低置信结果必须人工复核 |

状态展示建议：

| 状态 | UI 表达 |
| --- | --- |
| success / generated | 绿色或蓝色状态标签 |
| pending | 加载中状态，显示“AI分析中” |
| timeout | 黄色警示，提示“AI超时，已按规则结果展示” |
| error | 红色警示，提示“AI调用失败，可人工复核” |
| circuit_open | 灰黄色警示，提示“模型熔断中” |
| skipped_by_policy / skipped | 灰色标签，提示“策略跳过AI检测” |

### 4.4 AI检测结果 Tab

该 Tab 用于解释 AI 检测为什么命中。

建议模块：

| 模块 | 内容 |
| --- | --- |
| AI检测摘要 | 攻击类型、置信度、模型版本、Prompt模板版本、耗时、Token消耗 |
| 命中片段 | 原始证据字段、命中文本片段、风险标签 |
| 判断理由 | AI 判定依据，需与证据引用关联 |
| 反例提示 | AI 给出的可能误判原因或边界情况 |
| 降级信息 | timeout/error/circuit_open 时展示降级原因 |

交互要求：

- 命中片段点击后定位到证据链中的对应内容。
- 模型版本和 Prompt 模板版本可复制。
- 超时、错误、熔断状态下仍保留规则检测结果，不阻断人工研判。

### 4.5 AI研判卡片

AI研判卡片放在详情页右侧或主体上方高可见位置。

卡片字段：

| 字段 | 展示要求 |
| --- | --- |
| 攻击手法 | 简短标签 + 一句话说明 |
| 影响面评估 | 影响对象、影响范围、可能后果 |
| 处置优先级建议 | low / medium / high / critical |
| 判断理由 | 分点展示，不写成大段自然语言 |
| 置信等级 | high / medium / low，低置信突出显示 |
| 缺失证据 | 列表展示 |
| 需人工补充的问题 | 列表展示 |
| 模型版本 | 次要信息，便于追溯 |

操作按钮：

| 操作 | 说明 |
| --- | --- |
| 确认 | 采纳 AI 研判，状态改为 confirmed |
| 修正 | 打开修正弹窗，提交后状态改为 modified |
| 拒绝 | 需填写拒绝原因，状态改为 rejected |
| 补充证据 | 可关联人工补充的问题，作为后续增强入口 |

### 4.6 修正弹窗

弹窗字段建议：

| 字段 | 类型 | 必填 |
| --- | --- | --- |
| 修正后的攻击手法 | 下拉/输入 | 是 |
| 修正后的影响面 | 多行文本 | 是 |
| 修正后的处置优先级 | 单选 | 是 |
| 修正原因 | 多行文本 | 是 |
| 是否加入样本候选集 | 开关，默认开启 | 是 |
| 样本类型 | 误报 / 命中 / 攻击 / 边界 | 是 |

提交后行为：

1. AI 研判状态变为 modified。
2. 反馈记录写入 AI 研判结果。
3. 生成 sample_entry 候选样本。
4. 操作写入审计日志。

### 4.7 相似事件区域

P0.5a 只做基础版相似事件，不展示完整 RAG 可信度链路。

字段：

| 字段 | 说明 |
| --- | --- |
| 事件编号 | 可点击跳转 |
| 相似度 | 仅展示大于 0.8 的结果 |
| 关键相似点 | 如攻击类型、命中规则、主体、工具调用 |
| 历史处置结果 | 仅作参考，不自动继承 |

交互：

- 默认展示 Top 3。
- 支持展开查看更多。
- 明确标注“相似事件仅供参考”。

## 5. 页面二：风险事件列表

建议基于现有文件小改：

```text
pages/events/event-list.html
```

新增列或筛选项：

| 类型 | 内容 |
| --- | --- |
| 列 | 检测来源 |
| 列 | AI 研判状态 |
| 列 | 置信等级 |
| 筛选 | 规则检出 / AI检出 / 联合检出 |
| 筛选 | 待AI研判 / 已生成 / 待人工复核 / 已确认 / 已修正 / 已拒绝 |
| 快捷筛选 | 低置信待复核 |

列表交互：

- 点击低置信待复核事件进入详情页，并自动定位到 AI 研判卡片。
- timeout/error/circuit_open 状态以警示标签展示，避免被误认为无风险。

## 6. 页面三：操作审计日志

建议基于现有文件小改：

```text
pages/system/audit-log.html
```

新增审计类型：

| 类型 | 说明 |
| --- | --- |
| model_call_log | 模型调用记录 |
| ai_inference_record | AI 推理记录 |
| ai_judgement_feedback | AI 研判确认、修正、拒绝 |
| sample_feedback | 反馈回流样本库 |
| sensitive_access_log | 高敏证据访问审批与调用 |

筛选项：

- 操作类型
- 模型版本
- 数据级别 L0-L3
- 调用状态
- 审批编号
- 操作人

## 7. P0.5a 不包含内容

为避免原型范围膨胀，P0.5a 原型不包含以下能力：

| 暂不包含 | 后续期次 |
| --- | --- |
| 完整知识库可信度元数据 | P1/P2a |
| 知识检索安全扫描和完整 RAG 沙箱 | P1/P2a |
| AI 处置建议 | P3 |
| 自动响应规则管理 | P3 |
| 攻击链自动还原复杂图谱 | P2b |
| 跨应用风险关联分析 | P2a |
| 完整样本集流转和评估集冻结 | P1 |
