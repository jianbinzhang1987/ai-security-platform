## 5. 认领/分派流程交互

### 5.1 认领流程

```
事件创建 (assignee = null, status = pending)
    ↓
运营人员点击 [认领]
    ↓
┌─────────────────────────┐
│ 确认认领此事件?         │
│ EVT-20250430-008234     │
│                         │
│   [取消]  [确认认领]    │
└─────────────────────────┘
    ↓
assignee = 当前用户, assigned_at = now
写入审计日志 (action = claim)
通知原分派人（如有）
```

### 5.2 分派流程

```
管理员点击 [分派]
    ↓
┌─────────────────────────┐
│ 分派事件                │
│ EVT-20250430-008234     │
│                         │
│ 分派给: [选择用户 ▼]     │
│ 分派原因: [________]    │
│                         │
│ [取消]  [确认分派]      │
└─────────────────────────┘
    ↓
assignee = 指定用户
assigned_by = 当前用户
assigned_at = now
写入审计日志 (action = assign)
通知被分派人
```

### 5.3 转交流程

```
认领人点击 [转交]
    ↓
┌─────────────────────────┐
│ 转交事件                │
│ EVT-20250430-008234     │
│ 当前认领人: 张三         │
│                         │
│ 转交给: [选择用户 ▼]     │
│ 转交原因: [________]    │
│                         │
│ [取消]  [确认转交]      │
└─────────────────────────┘
    ↓
assignee = 新用户
previous_assignee = 旧用户
写入审计日志 (action = reassign)
通知新旧责任人
```

### 5.4 退回流程

```
认领人点击 [退回]
    ↓
┌─────────────────────────┐
│ 退回事件                │
│ EVT-20250430-008234     │
│                         │
│ 退回原因: [________]    │
│                         │
│ [取消]  [确认退回]      │
└─────────────────────────┘
    ↓
assignee = null
status = pending
写入审计日志 (action = unassign)
通知原责任人+分派人
```

## 6. 视图说明

### 6.1 全部事件视图

- 展示所有事件
- 默认按时间倒序
- 支持完整筛选

### 6.2 待我处理视图

```
筛选条件: assignee = 当前用户 AND status ≠ closed
排序规则:
1. 优先级: critical > high > medium > low
2. 同级别: AI状态排序
   generated(待确认) > pending(等AI) > 其他

统计概览:
- 待处理事件数
- 高危待处理数 (critical, 红色高亮)
- AI研判待确认数
- 今日已处理数

快捷操作:
- 一键认领 (未认领事件)
- 一键确认AI研判 (generated状态)
- 快速处置 (L1/L2动作)
```

### 6.3 未认领视图

- 筛选: assignee = null
- 排序: 等级降序 + 时间倒序
- 高危未认领事件红色高亮

### 6.4 高危未处理视图

- 筛选: level = critical AND status ≠ closed
- 展示所有高危且未关闭事件
- 30分钟未认领自动告警

## 7. 批量操作约束

| 操作类型 | 适用条件 | 确认要求 | 数量上限 | 高危约束 |
|----------|----------|----------|----------|----------|
| 批量认领 | 事件未认领 | 无需确认 | 50条 | — |
| 批量分派 | 事件未认领 | 需确认分派对象 | 50条 | — |

| 批量确认AI研判 | AI状态=generated | 无需确认 | 50条 | — |
| 批量处置(L1/L2) | 事件未处置 | 需选择处置动作 | 20条 | — |
| 批量处置(L3) | 事件未处置 | 需审批 | 10条 | — |
| 批量处置(L4) | **禁止** | — | — | L4必须逐条审批 |

## 10. 安全约束

1. **认领/分派审计**: 所有认领、分派、转交操作写入审计日志
2. **高危事件超时告警**: critical事件30分钟未认领自动告警管理员
3. **批量操作上限**: 单次批量操作不超过50条，L3不超过10条
4. **L4禁止批量**: L4级动作禁止批量执行，必须逐条审批
5. **通知脱敏**: 通知摘要中不包含L2/L3级别数据原文
