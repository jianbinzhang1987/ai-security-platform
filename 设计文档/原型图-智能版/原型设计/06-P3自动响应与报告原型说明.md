# 06-P3 自动响应与报告原型说明

> **版本**：v1.0  
> **期次**：P3（自动响应与报告增强）  
> **前置依赖**：P0.5a（核心闭环）、P0.5b（策略配置）、P1（知识库与评测治理）、P2（高级 SOC 分析）  
> **状态**：草稿

---

## 1. 目标与范围

### 1.1 目标

从"纯人工处置"升级为"**AI建议 + 受限自动响应 + 人工审批**"模式，同时支持 AI 自动生成安全报告并走人工审核流程。

### 1.2 范围边界

| 包含 | 不包含 |
|------|--------|
| 自动响应规则 CRUD（触发条件、L1-L4 动作分级、白名单、熔断、TTL、审批） | 外部工单系统集成 |
| 事件详情处置区 AI 建议面板 + 自动执行台账 | 自动化漏洞修复 |
| 安全报告 AI 自动生成 + 人工审核 + 发布 | 外部威胁情报接入 |
| 自定义报告 AI 模板选择与内容填充 | 多语言报告翻译 |
| 急停控制（全局/单规则/单租户） | 邮件/IM 实际发送通道 |

---

## 2. 核心用户

- **安全运营负责人**：配置自动响应规则、审批 L3/L4 动作、执行急停
- **SOC 分析师**：在事件详情中查看 AI 处置建议、确认/拒绝自动动作、手动恢复
- **安全报告管理员**：创建报告、审核 AI 生成内容、发布报告

## 4. 自动响应规则（新增）

### 4.1 页面定位

面向安全运营负责人的自动响应规则管理页面，支持规则配置、审批流转、急停控制和执行审计。

### 4.2 页面结构

```
+------------------------------------------------------------------+
| 页面标题：自动响应规则              [新建规则] [全局急停] [执行审计] |
+------------------------------------------------------------------+
| 统计卡行（4 张）                                                   |
| [启用规则 12] [今日自动执行 28] [待审批 3] [急停状态 正常]          |
+------------------------------------------------------------------+
| 搜索栏: 规则名称 / 触发风险类型 / 动作级别 / 审批状态 / 启用状态    |
+------------------------------------------------------------------+
| 规则列表表格:                                                       |
| | 规则名称 | 触发条件 | 动作级别 | 范围 | TTL | 审批状态 | 启用 | 操作 |
+------------------------------------------------------------------+
```

### 4.3 L1-L4 动作分级

| 级别 | 动作类型 | 可否自动 | 审批要求 | TTL | 灰度 | 回滚 | 影响范围 |
|------|----------|----------|----------|-----|------|------|----------|
| **L1 通知类** | 告警通知、消息推送 | ✅ 可自动 | 规则审批后启用 | 默认带 | 支持 | 无需回滚 | 单人 |
| **L2 观察类** | 标记观察、升级关注、加入监控名单 | ✅ 可自动 | 规则审批后启用 | 默认带 | 支持 | 移除标记 | 单会话 |
| **L3 软限制类** | 会话 TTL 限制、频率降级、工具调用次数限制 | ⚠️ 可自动(需白名单) | 规则审批 + 业务确认 | 必须 | 必须 | 自动恢复 | 单 Agent/单应用 |
| **L4 强控制类** | 应用降级、工具禁用、主体阻断、策略变更 | ❌ **不可自动** | 必须人工审批 + MFA | 必须 | 必须 | 必须支持 | 多应用/全局 |

### 4.4 新建/编辑规则弹窗

```
+------------------------------------------------------------------+
| Tab: [基础信息] [触发条件] [动作配置] [审批与灰度]                  |
+------------------------------------------------------------------+
| 基础信息: 规则名称 / 规则描述 / 优先级 / 启用状态                  |
| 触发条件: 风险类型多选 / 风险等级 / 检测来源 / 置信度阈值 /        |
|           时间窗口 / 触发次数阈值                                   |
| 动作配置: 动作级别(L1-L4 单选) / 具体动作类型 / 动作参数            |
|           L3 额外: 白名单对象选择 / 熔断阈值(影响N个会话暂停)        |
|           TTL: __ 分钟/小时/天 (自动恢复)                           |
| 审批与灰度: 审批状态 / 灰度比例 __% / 灰度目标(应用/租户)            |
|             审批记录时间线                                          |
+------------------------------------------------------------------+
```

### 4.5 急停控制面板

```
+------------------------------------------------------------------+
| 急停控制                                                          |
| [全局急停] — 所有自动响应规则暂停，已执行动作按 TTL 自然恢复         |
| [单规则暂停] — 选择规则暂停，已执行动作按 TTL 自然恢复              |
| [单租户暂停] — 选择租户暂停其所有自动响应                            |
| [批量恢复可逆动作] — 恢复所有 L2 标记 / L3 频率降级等可逆动作       |
+------------------------------------------------------------------+
| 约束：全局急停必须审计留痕；急停后需人工重新启用，不可自动恢复       |
+------------------------------------------------------------------+
```

### 4.6 执行审计

展示 `auto_response_execution` 记录：
- 执行时间 / 关联规则 / 关联事件 / 动作级别 / 执行结果 / 是否回滚 / 操作人

## 5. 风险事件详情（改造）

### 5.1 改造范围

在现有事件详情页处置区增加：

1. **AI 处置建议面板**：展示 AI 推荐的处置动作、级别、范围、TTL、影响评估
2. **自动执行台账**：展示该事件触发的所有自动响应执行记录
3. **TTL 倒计时**：对 L3 限制类动作显示剩余恢复时间
4. **恢复标记**：支持手动提前恢复（L2/L3）

### 5.2 AI 处置建议面板


## 8. 关键设计约束

### 8.1 安全约束

- L4 强控制类动作**绝对禁止自动执行**，界面必须显示红色警告
- 所有自动执行动作必须写入审计日志（谁/何时/执行了什么/是否回滚）
- L3 自动执行必须有白名单机制，仅对白名单内对象生效
- 自动响应规则必须审批后才可启用，支持灰度模式
- 全局急停操作必须审计留痕，急停后需人工重新启用

### 8.2 AI 约束

- AI 处置建议面板必须标注 "AI 建议"，不表达为最终决策
- AI 生成报告必须标注来源，所有数据需可追溯
- AI 生成内容发布前必须人工审核
- 报告中 AI 生成段落需与人工编辑段落区分标识

### 8.3 数据模型

| 实体 | 核心字段 |
|------|----------|
| `auto_response_rule` | rule_id, trigger_condition(JSON), action_level(L1-L4), action_type, action_config(JSON), whitelist, circuit_breaker_threshold, ttl_seconds, approval_status, enabled, gray_ratio |
| `auto_response_execution` | execution_id, rule_id, event_id, action_level, execution_result, executed_at, ttl_expired, rolled_back, rollback_by |

## 9. 验收检查清单

| 检查项 | 标准 | 验证方式 |
|--------|------|----------|
| L1-L4 分级配置 | 四种级别均可独立配置 | 弹窗验证 |
| L4 禁用自动执行 | L4 规则界面上"自动执行"选项禁用并标红 | 视觉检查 |
| 白名单配置 | L3 规则可配置白名单对象 | 表单验证 |
| 熔断阈值配置 | 可配置影响 N 个会话后暂停 | 表单验证 |
| TTL 配置 | 支持分钟/小时/天单位 | 表单验证 |
| 审批时间线 | 显示审批记录和当前状态 | 弹窗验证 |
| 灰度比例 | 支持 0-100% 灰度比例滑块 | 交互验证 |
| 全局急停 | 一键急停按钮，带二次确认 | 操作验证 |
| 事件详情 AI 建议面板 | 显示推荐动作/级别/范围/TTL/影响评估 | 视觉检查 |
| 自动执行台账 | 显示执行记录、TTL 倒计时、恢复按钮 | 视觉检查 |
| 报告 AI 生成入口 | 周报/月报 AI 生成按钮可用 | 交互验证 |
| 报告审核状态 | 未审核/审核中/已发布/已驳回状态流转 | 操作验证 |
| AI 生成标注 | 所有 AI 生成内容均有来源标注 | 全局检查 |
| 审计留痕 | 自动响应执行记录可查询 | 列表验证 |
