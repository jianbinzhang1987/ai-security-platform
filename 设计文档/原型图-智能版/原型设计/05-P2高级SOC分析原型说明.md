# 05-P2 高级 SOC 分析原型说明

> **版本**：v1.0  
> **期次**：P2（高级 SOC 分析）  
> **前置依赖**：P0.5a（核心闭环）、P0.5b（策略配置）、P1（知识库与评测治理）、身份归一与实体解析、行为基线数据积累  
> **状态**：草稿

---

## 1. 目标与范围

### 1.1 目标

将安全分析维度从单条 Trace/Span 扩展到**人员、组织、时序、关联、行为基线**五个维度，构建可下钻、可关联、可预测的高级 SOC 分析能力。

### 1.2 范围边界

| 包含 | 不包含（P3/P4 建设） |
|------|----------------------|
| 用户风险画像展示与下钻 | 自动化响应动作执行（P3） |
| 组织/业务线风险态势聚合 | 多租户间跨租户分析 |
| 行为基线配置与偏离告警 | 完整 AI 预测模型训练界面 |
| 攻击链路关联可视化 | 威胁情报外部接入 |
| 时序趋势与周期识别 | 自动化报告生成（P3） |

---

## 2. 核心用户

- **SOC 分析师**：进行多维风险分析、攻击链路还原、异常用户排查
- **安全运营负责人**：查看组织维度风险态势、高风险用户排行、行为基线覆盖
- **平台管理员**：配置行为基线、管理基线偏离告警阈值

## 4. 各页面详细设计

### 4.1 SOC 分析驾驶舱

#### 4.1.1 页面定位

五维分析的统一入口，以仪表盘形式聚合展示各维度核心指标，支持点击下钻到具体分析页面。

#### 4.1.2 页面布局

```
+------------------------------------------------------------------+
| 页面标题：SOC 分析驾驶舱          [导出] [刷新周期: 实时/5分钟/1小时] |
+------------------------------------------------------------------+
| 五维指标卡行（5 张）                                               |
| [人员: 高风险用户 12 人 ↑] [组织: 风险热点部门 3 个]              |
| [时序: 攻击趋势 ↑上升] [关联: 活跃攻击链 5 条]                   |
| [基线: 偏离告警 8 条]                                             |
+------------------------------------------------------------------+
| 左侧: 高风险用户 Top10 列表（可下钻人员分析）                      |
| 右侧: 攻击链路活跃态势（简化网络图，可下钻关联分析）               |
+------------------------------------------------------------------+
| 底部: 近 7 日风险时序趋势（堆叠面积图，按风险类型）               |
|       + 今日偏离告警时间线                                         |
+------------------------------------------------------------------+
```

#### 4.1.3 交互说明

- **五维指标卡**：点击任一卡片跳转对应分析页面，并携带当前时间范围
- **高风险用户列表**：hover 显示用户摘要风险评分，点击跳转"人员风险分析"
- **攻击链路简化图**：展示当前活跃攻击链数量，节点为应用/Agent，边为风险传播方向，点击跳转"风险关联分析"
- **时序趋势图**：支持切换近 7 天/30 天/90 天，hover 显示当日各风险类型数量
- **偏离告警时间线**：按时间顺序展示今日行为基线偏离告警，标注偏离类型和严重等级

### 4.2 人员风险分析

#### 4.2.1 页面定位

面向 SOC 分析师的用户级风险分析页面，聚合单用户跨应用、跨会话、跨时间的风险数据。

#### 4.2.2 页面结构

采用"用户列表 + 用户画像侧栏"的左右布局：

```
+------------------------------------------------------------------+
| 搜索栏: 用户标识 / 部门 / 业务线 / 风险等级 / 风险趋势                |
+------------------------------------------------------------------+
| 左侧: 用户风险列表（表格式）                                        |
| + 用户标识 | 部门 | 总风险评分 | 事件数 | 基线偏离 | 趋势 | 操作    |
+------------------------------------------------------------------+
| 右侧: 用户风险画像（点击用户后展开）                                |
| + 基本信息（用户标识、部门、业务线、账号创建时间）                  |
| + 风险评分仪表盘（0-100，按区间着色）                             |
| + 风险趋势折线图（近 30 日每日评分变化）                           |
| + 行为基线偏离卡片（偏离指标、偏离度、偏离时间）                    |
| + 跨会话风险累积时间线（会话级风险事件聚合）                        |
| + 关联风险事件列表（最近 10 条，可跳转事件详情）                   |
| + 跨应用风险分布（饼图/横向柱状图）                                 |
+------------------------------------------------------------------+
```

#### 4.2.3 字段与状态

| 字段 | 说明 |
|------|------|
| 用户标识 | 归一化后的用户唯一标识（支持跨应用映射） |
| 总风险评分 | 0-100，按阈值分级：≥80 高/50-79 中/<50 低 |
| 风险趋势 | ascending（上升）/ stable（平稳）/ descending（下降） |
| 基线偏离 | 偏离度 >2σ 标记为"异常"，≤2σ 为"正常" |
| 跨会话累积类型 | session_cross / application_cross / time_window |

#### 4.2.4 交互说明

- 用户列表支持按风险评分、事件数、偏离度排序
- 点击用户展开右侧画像侧栏，不跳转新页面
- 风险评分仪表盘：绿色(<30)、黄色(30-50)、橙色(50-80)、红色(≥80)
- 行为基线偏离卡片：点击可查看偏离详情（具体哪些指标偏离、偏离历史）
- 跨会话风险累积时间线：每个会话为一个节点，节点大小表示风险程度，节点间连线表示跨会话关联
- 关联风险事件：点击跳转事件详情页

### 4.3 风险关联分析

#### 4.3.1 页面定位

面向 SOC 分析师的关联分析页面，以可视化方式展示跨应用风险传播、工具传播链和攻击链路。

#### 4.3.2 页面结构

采用 Tab 切换三种分析视图：

```
+------------------------------------------------------------------+
| Tab: [跨应用风险传播] [工具传播链] [攻击链路关联]                    |
+------------------------------------------------------------------+
|                                                                  |
| 视图 1: 跨应用风险传播图（力导向图/层次图）                        |
| - 节点: 应用（按风险等级着色：红/橙/黄/绿）                        |
| - 边: 共享工具/资源/模型的传播路径（按传播风险权重着色和粗细）       |
| - 交互: 点击节点查看应用详情，点击边查看传播详情                   |
|                                                                  |
| 视图 2: 工具传播链（树形/层次布局）                                |
| - 根节点: 高风险工具                                               |
| - 子节点: 调用该工具的 Agent/应用                                  |
| - 叶节点: 具体的风险事件                                           |
| - 交互: 展开/折叠，点击节点跳转对应详情                            |
|                                                                  |
| 视图 3: 攻击链路关联（时间轴 + 拓扑图混合）                        |
| - 顶部: 时间轴，展示攻击链各阶段的时间分布                         |
| - 主体: 拓扑图，展示攻击者在不同 Trace 中的行为关联                  |
| - 节点: 攻击行为（如"Prompt注入"→"工具越界"→"数据外发"）           |
| - 交互: 点击节点查看原始 Trace 证据                                |
|                                                                  |
+------------------------------------------------------------------+
| 底部信息栏: 选中节点/边的详细信息卡片                               |
+------------------------------------------------------------------+
```

#### 4.3.3 数据要求

| 分析类型 | 数据源 | 关键字段 |
|----------|--------|----------|
| 跨应用传播 | 应用拓扑关系 + 风险事件 | shared_tools, shared_resources, risk_score |
| 工具传播链 | 工具注册表 + 调用日志 + 风险事件 | tool_id, agent_id, app_id, risk_level |
| 攻击链路 | Trace 数据 + 用户标识归一 + 时间窗口 | user_identifier, trace_id, timestamp, risk_type |

### 4.4 行为基线管理

#### 4.4.1 页面定位

面向平台管理员和安全运营负责人，用于配置和管理应用/Agent 的行为基线，查看偏离告警。

#### 4.4.2 页面结构

```
+------------------------------------------------------------------+
| Tab: [基线配置] [偏离告警] [全局异常检测]                           |
+------------------------------------------------------------------+
|                                                                  |
| 基线配置 Tab:                                                     |
| + 搜索: 基线名称 / 目标类型(应用/Agent) / 状态                     |
| + 基线列表:                                                        |
|   | 基线名称 | 目标 | 指标 | 窗口 | 基线值(均值/σ) | 状态 | 操作   |
| + 新建基线按钮 → 弹窗配置                                          |
|                                                                  |
| 新建基线弹窗:                                                      |
| + 基线名称 / 目标类型 / 目标选择(下拉)                             |
| + 监控指标: 调用频率 / 工具使用种类 / Prompt模式多样性 / 响应时长   |
| + 计算窗口: 1小时/1天/7天/30天                                    |
| + 偏离阈值: 偏离度 > __ σ 标记异常                                  |
| + 告警配置: 告警级别 / 通知渠道 / 抑制窗口                         |
|                                                                  |
| 偏离告警 Tab:                                                     |
| + 告警列表:                                                        |
|   | 告警时间 | 目标 | 指标 | 当前值 | 基线值 | 偏离度 | 级别 | 状态 |
| + 批量操作: 确认 / 忽略 / 加入白名单                                |
|                                                                  |
| 全局异常检测 Tab:                                                 |
| + 异常事件列表（统计模型检测结果）                                   |
| + 异常类型分布（聚类结果可视化）                                    |
| + 异常趋势（近 30 日异常数量趋势）                                  |
|                                                                  |
+------------------------------------------------------------------+
```

#### 4.4.3 基线偏离告警状态

| 状态 | 说明 |
|------|------|
| 未确认 | 新产生告警，待分析师确认 |
| 已确认 | 分析师确认为真实偏离 |
| 误报 | 分析师标记为误报，可自动优化基线 |
| 已忽略 | 已加入白名单，同类型不再告警 |
| 处理中 | 已创建处置工单，正在处理 |

### 4.5 组织风险态势

#### 4.5.1 页面定位

面向安全运营负责人的组织维度风险视图，按业务线、部门、租户聚合风险数据。

#### 4.5.2 页面结构

```
+------------------------------------------------------------------+
| 视图切换: [业务线视角] [部门视角] [租户视角]                         |
| 时间范围: [今日] [近7日] [近30日] [本季度]                          |
+------------------------------------------------------------------+
|                                                                  |
| 业务线视角:                                                       |
| + 业务线风险卡片矩阵（每个业务线一张卡片）                          |
|   卡片内容: 业务线名称 | 风险评分 | 事件数 | 应用数 | 热点应用     |
|   卡片颜色: 按风险评分区间着色（绿/黄/橙/红）                       |
| + 业务线对比表格（排序、下钻到该业务线应用列表）                    |
|                                                                  |
| 部门视角:                                                         |
| + 组织结构树 + 风险热力图                                         |
| + 部门级风险指标: 人均风险事件、风险处置效率、基线覆盖率            |
|                                                                  |
| 租户视角:                                                         |
| + 租户级风险聚合（多租户场景）                                     |
| + 跨租户风险传播警示（如共享模型/工具导致的风险扩散）               |
|                                                                  |
+------------------------------------------------------------------+
```

#### 4.5.3 组织维度指标

| 指标 | 定义 |
|------|------|
| 业务线风险评分 | 该业务线下所有应用风险事件的加权聚合 |
| 热点应用 | 该业务线内风险事件数 Top3 应用 |
| 人均风险事件 | 部门成员平均每人关联的风险事件数 |
| 风险处置效率 | 已处置事件数 / 总事件数（按部门） |
| 基线覆盖率 | 已配置行为基线的应用 / 部门总应用数 |

## 5. 关键设计约束

### 5.1 数据依赖

| 能力 | 前置数据条件 | 状态 |
|------|-------------|------|
| 用户风险画像 | 身份归一与实体解析完成 | P1 建设 |
| 行为基线偏离检测 | 至少 30 天历史行为数据 | P1 积累 |
| 跨应用风险传播 | 应用/Agent/工具拓扑关系维护 | P1 建设 |
| 攻击链路关联 | 用户标识归一 + Trace 关联规则 | P2a 建设 |
| 组织维度聚合 | 用户→部门→业务线映射关系 | P1 建设 |

### 5.2 AI 结果展示约束

- 所有 AI 分析结论（如攻击链预测、行为偏离判断）必须标注"AI 分析"标识
- 预测类结论（如攻击链下一步预测）用虚线/半透明表示，不表达为确定事实
- 行为基线偏离告警必须展示偏离的具体指标和量化偏离度
- 攻击链路关联必须支持人工确认/拆分/合并操作

### 5.3 性能约束

- SOC 驾驶舱首次加载 ≤ 3s，后续刷新 ≤ 1s
- 关联分析图节点数 ≤ 200 时保持流畅交互
- 用户画像侧栏展开 ≤ 500ms
- 全局异常检测支持近 7/30/90 天时间窗口切换

## 6. 验收检查清单

| 检查项 | 标准 | 验证方式 |
|--------|------|----------|
| SOC 驾驶舱五维指标卡 | 5 张卡片均有点击下钻能力 | 点击跳转 |

| 风险评分仪表盘 | 0-100 分区间正确着色 | 视觉检查 |
| 跨应用传播图 | 节点/边可点击，展示详情 | 交互验证 |
| 攻击链时间轴 | 已发生/当前/预测节点区分明确 | 视觉检查 |
| 行为基线配置 | 支持新建/编辑/停用基线 | 表单验证 |
| 偏离告警处理 | 支持确认/忽略/白名单操作 | 操作验证 |
| 组织视角切换 | 业务线/部门/租户三种视角可切换 | Tab 切换 |
| 知识检索侧栏 | 自动匹配当前 Trace 关联知识 | 侧栏验证 |
| AI 标识规范 | 所有 AI 分析结论均有"AI 分析"标识 | 全局检查 |
| 预测结论表达 | 攻击链预测用虚线/半透明 | 视觉检查 |
