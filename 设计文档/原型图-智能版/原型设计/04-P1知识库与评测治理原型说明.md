# P1 知识库与评测治理原型说明

## 1. 目标

P1 阶段在 P0.5a 闭环与 P0.5b 策略增强基础上，建设**知识库安全治理**与**样本评测体系**，让 AI 检测能力可管理、可评估、可迭代。

1. 知识库管理：为 AI 检测提供可溯源、可审计的安全知识来源。
2. 样本库管理：建立误报/命中/攻击/边界样本的闭环治理。
3. 模型效果评估：量化 AI 模型在安全场景下的准确率，建立上线门禁。
4. 高级规则 AI 优化建议：基于样本积累自动生成规则调优建议。

## 2. 核心用户

| 用户 | 主要诉求 |
|---|---|
| AI 安全研究员 | 维护知识库条目、审核知识来源、控制 RAG Prompt 安全风险 |
| 安全运营人员 | 标注和审核样本、查看模型评测结果、决定是否采纳 AI 优化建议 |
| 策略运营人员 | 基于模型评估结果选择上线模型版本、调整置信度阈值 |

## 3. 页面范围

| 页面 | 类型 | 所属模块 | 原型目标 | 优先级 |
|---|---|---|---|---|
| 知识条目管理 | 新增 | 知识库管理 | 知识库 CRUD、版本、安全标记、审核 | P0 |
| 样本库管理 | 新增 | 知识库管理 | 误报/命中/攻击/边界样本列表、标注、AI辅助标注 | P0 |
| 模型效果评估 | 新增 | 知识库管理 | 评测集管理、模型版本对比、准确率看板 | P0 |
| 高级规则项 AI 优化建议 | 激活 | 统一策略中心 | 从占位状态激活，展示样本分析+规则调整建议+干跑验证 | P1 |

## 4. 知识条目管理（新增 pages/knowledge/knowledge-item.html）

### 4.1 页面定位

顶级导航新增 **"知识库管理"** 模块，下含：

```
知识库管理
  ├── 知识条目管理
  ├── 样本库管理
  └── 模型效果评估
```

### 4.2 列表结构

| 字段 | 说明 |
|---|---|
| 知识 ID | knowledge_id |
| 标题 | 简要描述 |
| 风险类型 | 提示词攻击 / 工具越界 / 敏感数据 / 意图偏移 / 通用 |
| 安全级别 | 内部 / 机密 / 公开（默认公开） |
| 审核状态 | 草稿 / 待审核 / 已发布 / 已撤回 |
| 版本号 | v1.0 / v1.1 / v2.0 |
| 来源 | 人工录入 / AI生成 / 外部导入 |
| 关联事件数 | 该知识条目被多少事件引用 |
| 更新人 / 更新时间 | |
| 操作 | 查看 / 编辑 / 版本历史 / 撤回 / 删除（仅草稿） |

### 4.3 筛选项

- 风险类型、审核状态、安全级别、来源、更新时间

### 4.4 新增/编辑知识条目

字段：

| 字段 | 类型 | 必填 |
|---|---|---|
| 标题 | 文本 | 是 |
| 内容 | 富文本 / Markdown | 是 |
| 风险类型 | 下拉 | 是 |
| 安全级别 | 下拉 | 是 |
| RAG Prompt 模板关联 | 多选（可选） | 否 |
| 附件 | 上传（最多5个） | 否 |
| 标签 | 多选标签 | 否 |

### 4.5 版本历史

知识条目详情页有"版本历史"Tab，展示：
- 版本号、变更人、变更时间、变更摘要、diff 对比入口
- diff 弹窗展示前后内容差异（行内对比）

### 4.6 RAG Prompt 安全沙盒预览

在知识条目详情页增加 **"RAG 预览"** 按钮，弹窗展示：
- 该知识条目被 Prompt 引用时的片段形态
- 提示风险等级：高（机密级被公开引用）/ 中 / 低
- 建议：添加数据级别匹配约束

## 5. 样本库管理（新增 pages/knowledge/sample-library.html）

### 5.1 页面定位

知识库管理 → 样本库管理

### 5.2 样本集 Tab 结构

```
样本库管理
  ├── 候选集 Tab    [所有流入样本，未标注]
  ├── 训练集 Tab    [已标注、用于模型微调]
  ├── 评估集 Tab    [已标注、用于效果评估]
  └── 回收站 Tab    [已废弃样本]
```

### 5.3 样本列表结构

| 字段 | 说明 |
|---|---|
| 样本 ID | sample_id |
| 来源 | 事件回流 / 手动导入 / AI生成 |
| 关联事件 | EVT-xxx（可跳转） |
| 样本类型 | 命中样本 / 误报样本 / 攻击样本 / 边界样本 |
| 风险阶段 | prompt / plan / tool / resource / output |
| 原始文本 | 脱敏预览（前200字符） |
| 标注状态 | 待标注 / AI预标注 / 已审核 / 争议 |
| 标注结果 | 有风险 / 无风险 / 边界情况 |
| 模型版本 | 关联的模型版本号 |
| 回流时间 | |
| 操作 | 标注 / 查看详情 / 移入训练集 / 移入评估集 / 废弃 |

### 5.4 标注弹窗

点击"标注"打开：

| 字段 | 类型 |
|---|---|
| 样本类型 | 下拉：命中 / 误报 / 攻击 / 边界 |
| 标注结果 | 单选：有风险 / 无风险 / 边界情况 |
| 置信度评分 | 滑块 0-1 |
| 风险阶段 | 多选：prompt/plan/tool/resource/output |
| 风险类型 | 多选 |
| 说明 | 文本域 |
| AI 预标注结果 | 只读展示（如果存在） |

### 5.5 AI 辅助标注

- 批量选择样本 → "AI 辅助标注" 按钮
- 选择目标模型 → 提交
- 结果在列表中以"AI预标注"状态展示，待人工确认

### 5.6 评估集管理

评估集 Tab 特有操作：
- 新建评估集：输入名称、选择样本（从候选集/训练集勾选）
- 评估集详情：展示包含样本数、已评测模型列表、最新准确率
- 运行评测：选择模型版本，触发评测任务（异步）
- 评测结果：正确数/错误数/准确率/召回率/F1

## 6. 模型效果评估（新增 pages/knowledge/model-evaluation.html）

### 6.1 页面定位

知识库管理 → 模型效果评估

### 6.2 页面结构

```
页面标题区：模型效果评估看板

Tab 切换：
  ├── 评测任务列表
  ├── 模型版本对比
  └── 指标趋势
```

### 6.3 评测任务列表

| 字段 | 说明 |
|---|---|
| 任务 ID | eval_task_id |
| 模型版本 | model_version |
| 评估集 | eval_set_name |
| 状态 | 进行中 / 已完成 / 失败 |
| 准确率 | 百分比 |
| 召回率 | 百分比 |
| F1 分数 | |
| 评测时间 | |
| 操作 | 查看报告 / 对比基准 / 删除 |

### 6.4 评测报告详情

点击"查看报告"展开或弹窗：

- 总体指标卡：准确率 / 召回率 / F1 / 误判数 / 漏判数
- 混淆矩阵表格
- 按风险类型拆分：各类型准确率
- 错误样本 Top 10 列表（可跳转到样本详情）
- 与上一版本对比：提升/下降箭头 + 差值

### 6.5 模型版本对比

- 选择两个模型版本 + 同一个评估集
- 对比维度：准确率差、召回率差、各风险类型表现差、错误样本交集/差集
- 结果表格展示，差异项高亮

### 6.6 上线门禁建议

在评测报告底部增加"上线建议"区域：

| 条件 | 建议 |
|---|---|
| 准确率 >= 目标阈值 && 误判率 < 容忍阈值 | 建议上线 |
| 准确率 < 目标阈值 | 建议优化后重测 |
| 误判率 >= 容忍阈值 | 建议增加负样本训练 |
| 召回率下降 | 建议检查边界样本 |

## 7. 高级规则项 AI 优化建议（激活 pages/policy/shared-rules.html）

### 7.1 激活条件

当规则关联的样本数 >= 10 条（命中+误报合计），且知识库中已有至少 1 条该风险类型的知识条目时，"AI 优化建议" Tab 从占位状态激活为可用状态。

### 7.2 Tab 内容

```
AI 优化建议
  ├── 样本分析
  ├── 规则调整建议
  └── 干跑验证
```

#### 样本分析

- 该规则关联样本总数、类型分布饼图（命中/误报/攻击/边界）
- 误报 Top 3 原因分析（从标注说明中聚类）
- 规则当前阈值 vs 样本实际分布直方图

#### 规则调整建议

- 建议列表（AI 生成，每条建议包含）：
  - 建议类型：调整阈值 / 补充关键词 / 改用 AI 增强 / 拆分规则
  - 建议内容：具体调整数值或关键词
  - 预期效果：预计准确率提升 / 误报率下降
  - 置信度：AI 建议的可信度
  - 操作：采纳建议（直接修改规则） / 忽略 / 加入评估集验证

#### 干跑验证

- 选择历史时间范围（如近7天）
- 点击"干跑验证"：用建议调整后的规则逻辑在历史数据中重跑
- 结果对比：
  - 原规则检出数 vs 新规则检出数
  - 误报减少数 / 新增命中数 / 新增误报数
  - 建议：继续优化 / 确认生效
