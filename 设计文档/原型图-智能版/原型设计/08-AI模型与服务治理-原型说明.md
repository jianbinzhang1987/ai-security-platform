**步骤2: 连接配置**
```
│ Endpoint: [https://api.openai.com/v1/chat/completions] │
```

**步骤3: 安全配置**
```
│ 部署模式: [Cloud ▼] (private/cloud/local)              │
│ 最高数据级别: [L1 ▼] (L0-L3)                           │
│ 初始状态: registered (注册后需创建版本才能testing)     │
```

### 2.3 交互说明

| 操作 | 前置条件 | 交互效果 |
|------|----------|----------|
| 新建模型 | 无 | 打开三步弹窗，完成创建后状态=registered |
| 查看版本 | 模型已注册 | 跳转到模型详情页，定位到版本管理Tab |
| 上线 | 至少一个版本 gate_status=passed | 状态→online，灰度切量从0%开始 |
| 下线 | 无正在执行的推理任务 | 状态→offline，路由层停止转发 |
| 编辑 | 模型状态≠online | 修改endpoint/auth_ref需审批 |

## 7. 关键状态与图标定义

### 7.1 模型状态

| 状态 | 图标/颜色 | 说明 |
|------|-----------|------|
| registered | ⚪ 灰色 | 已注册，待创建版本 |
| testing | 🟡 黄色 | 版本测试中 |
| online | 🟢 绿色 | 已上线运行 |
| offline | 🔴 红色 | 已下线 |

### 7.2 版本状态

| 状态 | 说明 |
|------|------|
| draft | 草稿，未提交评测 |
| testing | 评测中 |
| canary | 灰度发布中 |
| production | 生产版本 |

### 7.3 熔断器状态

| 状态 | 图标 | 说明 |
|------|------|------|
| CLOSED | 🟢 | 正常，请求通过 |
| OPEN | 🔴 | 已熔断，请求被拒绝 |
| HALF_OPEN | 🟡 | 探测中，允许少量请求测试 |

### 7.4 告警级别

|------|------|------|

## 9. 安全约束

1. **模型endpoint密钥不落前端**: `auth_ref`仅存储引用，前端展示脱敏后值
2. **Prompt系统提示词修改需审批**: 修改`system_prompt`需安全负责人审批
3. **灰度切量需二次确认**: 扩大流量百分比操作需弹窗二次确认
4. **熔断器手动操作需审计**: 手动恢复/强制熔断操作写入审计日志
5. **预算硬限不可绕过**: 硬限触发后仅规则引擎运行，不可通过API绕过
