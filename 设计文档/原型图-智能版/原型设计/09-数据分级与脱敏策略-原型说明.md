## 5. 分级定义参考

### 5.1 四级分级体系

| 数据级别 | 图标 | 内容定义 | AI调用策略 | 脱敏要求 |
|----------|------|----------|------------|----------|
| **L0 公开** | 🟢 | 脱敏后的结构化摘要、聚合统计 | 可传外部模型 | 否 |
| **L1 内部** | 🔵 | 脱敏证据文本、风险标签、事件摘要 | 可传私有化模型，外部需审批 | 是 |
| **L2 敏感** | 🟡 | 含PII的Prompt原文、Raw证据 | 仅传私有化模型，禁止外部API | 是 |
| **L3 机密** | 🔴 | 完整用户输入、未脱敏原始数据、密钥 | 仅本地模型，禁止任何外部传输 | 是 |

### 5.2 判定流程

```
字段数据级别判定流程:
1. 按 target_object + field_path 查找匹配规则
2. 按 priority 降序排列
3. 依次评估 condition_expression:
   - 首个匹配的规则 → 返回其 default_level
   - 无条件匹配 → 返回最高优先级规则的 default_level
4. 无任何规则 → 默认 L1 (内部, 保守策略)
```

## 7. 安全约束

1. **无规则字段默认L1**: 未配置分级规则的字段默认为L1（内部），保守策略
2. **脱敏规则变更需审批**: 修改脱敏规则需安全负责人审批，变更后版本号+1
3. **L3访问需MFA**: 审批L3数据访问时审批人需MFA验证
4. **脱敏不可逆**: 脱敏后数据不可还原，原文仅加密存储于对象存储
5. **分级规则优先级冲突检测**: 新增规则时自动检测与已有规则的字段路径冲突
