## 3. 关键组合流程

### 3.1 用户请求流程中的模块组合

```
1. 用户通过Agent中心或应用访问Agent

2. 应用层权限检查
   Agent中心检查用户是否有权使用此Agent
   → 调用SUP查询权限（或本地缓存）

3. 请求发送到网关
   请求: 用户身份 + 资源ID + 操作参数
   
4. 网关权限检查 (Higress扩展)
   查询本地缓存的授权规则
   决策: 允许 / 拒绝
   
5. 网关输入检测
   提示词检测、内容合规检查等
   如果检测失败 → 拒绝 + 事件记录
   
6. 转发请求
   网关转发到Agent中心或后端能力
   
7. 处理返回
   收到响应
   
8. 网关输出检测
   有害内容检测、泄露风险检测等
   如果检测失败 → 脱敏/拒绝 + 事件记录
   
9. 返回给用户
   
10. 事件推送
    推送所有安全相关事件到安全平台
    
11. 安全平台分析
    聚合事件、关联分析、触发告警
    如需要 → 下发新策略到网关
```

### 3.2 安全响应流程中的模块组合

```
1. 安全平台检测到异常

2. 威胁评估
   评估威胁等级
   决定是否需要立即响应

3. 自动响应（低风险）
   - 阻止该身份的后续请求
   - 隔离异常Agent
   - 下发更严格的检测策略

4. 人工审批（高风险）
   - 告警通知管理员
   - 等待审批
   - 执行批准的响应

5. 策略下发
   生成新策略
   灰度发布到Higress
   逐步推送到所有网关

6. 客户端通知
   推送策略更新到客户端SDK
   
7. 应用层通知
   推送策略更新到Agent中心
```

### 3.3 开发发布流程中的模块组合

```
1. 开发者在开发平台创建Agent
   
2. 配置能力
   - 选择大模型（检查SUP权限）
   - 选择Skills（检查SUP权限）
   - 选择知识库（检查SUP权限）
   - 选择MCP服务（检查SUP权限）

3. 本地测试
   在开发平台测试
   不涉及网关权限检查（开发环境）

4. 灰度发布
   发布到部分用户/环境
   网关开始进行权限检查和安全检测

5. 全量发布
   发布到Agent中心
   所有用户都可以使用

6. 上线监控
   Agent中心展示运行指标
   安全平台监控安全事件
```

## 5. 集成依赖关系

```
开发平台
   ↓ (依赖)
   SUP (查询资源授权)
   AI智能网关 (转发测试请求)
   
Agent中心
   ↓ (依赖)
   SUP (查询用户权限)
   AI智能网关 (转发请求、调用后端)
   安全平台 (接收安全策略)
   
AI智能网关
   ↓ (依赖)
   SUP (权限检查、身份验证)
   AI安全平台 (接收策略、事件分析)
   后端服务 (转发请求)
   
AI安全平台
   ↓ (依赖)
   AI智能网关 (接收网关事件)
   Agent中心 (接收应用事件)
   客户端 (接收端侧事件)
```
