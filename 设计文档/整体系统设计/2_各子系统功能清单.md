# 各子系统功能清单

## 1. SUP 平台 (Static & Authorization Unified Platform)

### 负责部门：平台部

### 1.1 核心功能模块

#### 1.1.1 静态资源授权管理

| 功能模块 | 功能描述 | 实现方式 | 责任方 |
|---------|--------|--------|------|
| 大模型授权管理 | 管理哪些身份/应用可以调用哪些大模型 | Higress扩展 + SUP后端服务 | 平台部 |
| Agent授权管理 | 管理Agent的使用权限和访问控制 | Higress扩展 + SUP后端服务 | 平台部 |
| Skills授权管理 | 管理Skills能力的调用权限 | Higress扩展 + SUP后端服务 | 平台部 |
| 知识库授权管理 | 管理知识库的访问权限 | Higress扩展 + SUP后端服务 | 平台部 |
| MCP授权管理 | 管理MCP服务的调用权限 | Higress扩展 + SUP后端服务 | 平台部 |
| 资源目录管理 | 维护静态资源的元数据和分类 | SUP后端 + UI | 平台部 |
| 授权规则定义 | 定义灵活的授权规则（RBAC/ABAC） | SUP UI + 后端 | 平台部 |
| 权限检查与验证 | 在请求时验证权限 | Higress扩展（实时检查） | 平台部 |
| 授权日志记录 | 记录所有授权相关操作 | SUP后端 | 平台部 |
| 审计与监控 | 提供审计报表和监控 | SUP UI | 平台部 |

**服务调用关系：**
- 当 AI智能网关 收到请求时，通过 Higress 扩展调用 SUP 授权服务
- 检查该身份/应用是否有权限调用特定资源
- 返回允许/拒绝结果

#### 1.1.2 身份授权管理

| 功能模块 | 功能描述 | 实现方式 | 责任方 |
|---------|--------|--------|------|
| 用户身份管理 | 创建、更新、删除用户身份 | SUP UI + 后端 | 平台部 |
| 应用身份管理 | 创建、管理第三方应用身份 | SUP UI + 后端 | 平台部 |
| 身份认证 | 支持用户/应用的认证（SSO集成） | SUP后端 + 网关 | 平台部 |
| 用户组管理 | 创建和管理用户组 | SUP UI + 后端 | 平台部 |
| RBAC权限管理 | 定义角色和权限 | SUP UI + 后端 | 平台部 |
| Token与Session管理 | 管理认证Token和会话 | SUP后端 | 平台部 |
| 审计日志 | 记录身份相关操作 | SUP后端 | 平台部 |

**服务调用关系：**
- 所有外部请求都需要通过 AI智能网关 的身份验证
- AI智能网关 向 SUP 查询身份信息和权限

### 1.2 数据流

```
请求 → [验证身份] → [查询SUP身份服务] → 确定身份信息
                ↓
            [查询权限] → [查询SUP授权服务via Higress] → 确定是否有权限
                ↓
            [执行] 或 [拒绝]
```

### 1.3 与其他系统的交互

- **AI智能网关**：提供授权和身份验证服务
- **Agent中心**：提供Agent权限信息
- **智能体开发平台**：提供能力授权信息
- **AI安全平台**：提供审计日志和统计数据

## 2. AI 智能网关 (AI Gateway with Security)

### 负责部门：平台部（大部分） + 网络部（输入输出管控）

### 2.1 核心功能模块

#### 2.1.1 业务授权管理层

| 功能模块 | 功能描述 | 实现方式 | 责任方 |
|---------|--------|--------|------|
| 身份认证 | 验证请求的身份 | 网关 + SUP认证服务 | 平台部 |
| 权限检查 | 检查身份是否有权限 | Higress扩展 + SUP授权服务 | 平台部 |
| 大模型调用授权 | 检查是否可以调用特定大模型 | Higress扩展 | 平台部 |
| Agent能力授权 | 检查是否可以使用特定Agent | Higress扩展 | 平台部 |
| Skills能力授权 | 检查是否可以调用特定Skills | Higress扩展 | 平台部 |
| 知识库访问授权 | 检查是否可以访问特定知识库 | Higress扩展 | 平台部 |
| MCP调用授权 | 检查是否可以调用MCP服务 | Higress扩展 | 平台部 |
| Token生成与验证 | 生成和验证访问Token | 网关后端 | 平台部 |
| 速率限制 | 实现请求频率限制 | Higress扩展 | 平台部 |
| 黑白名单管理 | 管理IP/身份黑白名单 | Higress扩展 | 平台部 |

**Higress扩展范围**：
- 权限检查都通过Higress扩展实现
- 扩展通过HTTP调用SUP服务获取授权规则

### 2.2 数据流

```
请求流：
用户请求 → 网关接收
          ↓
        [Higress层：身份认证、权限检查、速率限制]
          ↓
        [网关后端：输入安全检测]
          ↓
        [转发到后端服务(大模型/Agent/Skills/KB/MCP)]
          ↓
        [网关后端：输出安全检测]
          ↓
        返回响应给用户

安全事件流：
检测到安全事件 → 记录到日志
               ↓
            推送到 AI安全平台
               ↓
            AI安全平台进行分析
```

### 2.3 与其他系统的交互

- **SUP平台**：查询授权规则、身份信息
- **AI安全平台**：推送安全事件、接收安全策略
- **后端服务**：转发请求、获取响应
- **用户/应用**：接收请求、返回响应
