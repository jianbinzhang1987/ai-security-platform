## 2. 核心系统模块分解

**负责部门：平台部**

**层次分解：**
```
AI 智能网关

│  ├─ 大模型调用授权
│  ├─ Agent能力授权
│  ├─ Skills能力授权
│  ├─ 知识库访问授权
│  ├─ MCP服务授权
│  └─ 身份校验与Token管理
│
├─ AI安全检测层 (AI Security Detection)
│  ├─ 输入侧安全检测
│  │  ├─ 提示词注入攻击检测
│  │  ├─ SQL注入/命令注入检测
│  │  ├─ 内容合规性检查
│  │  └─ 格式/签名校验
│  │
│  ├─ 输出侧安全检测
│  │  ├─ 有害内容识别
```

## 3. 系统间的数据流与交互关系

```
用户请求流：

用户 → Agent中心 / 智能体应用
        ↓
    AI智能网关
    ├─ 1. 身份验证 (SUP提供身份服务)
    ├─ 2. 权限检查 (SUP的Higress扩展检查授权)
    ├─ 3. 输入安全检测
    ├─ 4. 转发请求到大模型/Skills/知识库等
    ├─ 5. 输出安全检测
    └─ 6. 返回结果

安全监测流：

AI智能网关安全事件 → AI安全管理中心
Agent异常行为 → AI安全管理中心
客户端异常 → AI安全管理中心

AI安全管理中心 → 分析与决策
                ↓
            发送安全策略与告警 → Agent中心 / 智能体应用 / AI智能网关

静态资源授权流：

Agent中心需要调用某个大模型/Skills → 查询SUP授权状态
                                    ↓
                                 检查权限 (Higress扩展)
                                    ↓
                                 允许/拒绝

知识库访问流：

智能体应用 → AI智能网关 → 知识库授权检查 (SUP) → 知识库系统
```

## 4. 核心集成点

| 集成点 | 源系统 | 目标系统 | 集成方式 | 数据类型 |
|--------|--------|--------|--------|--------|
| 身份认证 | AI智能网关 | SUP平台 | API调用 | 用户身份信息 |

| 安全事件 | Agent中心 | AI安全中心 | 事件推送/API | 行为事件 |
| 安全事件 | 客户端 | AI安全中心 | 事件推送/API | 客户端事件 |
| 安全策略 | AI安全中心 | AI智能网关 | API/配置下发 | 策略配置 |
| 安全策略 | AI安全中心 | Agent中心 | API/配置下发 | 策略配置 |
| 安全策略 | AI安全中心 | 客户端 | API/配置下发 | 策略配置 |
| 授权规则 | SUP平台 | Higress扩展 | 配置同步 | 授权规则 |
