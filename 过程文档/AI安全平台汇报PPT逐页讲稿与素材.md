## 一、整体汇报建议

### 汇报主线

本次汇报建议围绕一个主线展开：

> 我们将“网关防护、静态检测、动态运行时检测、知识库安全、Agent 安全联动”统一整合为 AI 安全平台，形成从网络入口到服务器运行态、从 Agent 配置到知识库内容、从实时拦截到审计闭环的一体化安全能力。

### 汇报口径

- 对外统一叫：**AI 安全平台**。
- 内部能力分层：**网关防护子系统 + 安全治理子系统 + 探针/SDK 接入层**。
- 与 Agent 中心关系：Agent 中心提供智能体运行上下文，AI 安全平台提供安全检测、风险判断和处置能力。
- 与 Higress 关系：Higress 是通用网关底座，我们在其上增强 AI 协议、Prompt 检测、Token 配额、MCP/Skill 审计、PII 脱敏和安全运营闭环。
- 与团队A关系：团队A做统一身份、授权、资源底座；我们做 AI 应用运行安全、Agent 行为审计、知识库投毒检测和安全闭环。

## 第 3 页：为什么现在必须做 AI 安全平台

### 页面标题

AI 应用的风险已经从“模型调用”扩展到“Agent 行为链”

### 页面内容

传统 AI 安全关注点：

- Prompt 是否违规。
- 输出是否含敏感词。
- Token 是否超限。
- 接口是否鉴权。

现在 Agent 场景新增风险：

- Agent 可调用 MCP/Skill，风险从“说错话”变成“做错事”。
- 知识库/RAG 可能被投毒，恶意指令藏在文档中。
- Agent 运行在服务器/容器中，可能读取文件、执行命令、外联网络。
- 单次请求无法说明完整风险，必须还原 Session / Trace / 工具调用链。

### 讲解稿

过去的大模型安全更多是输入输出拦截，但 Agent 出现后，模型不只是回答问题，还会调用工具、访问知识库、执行任务。风险从内容安全扩展到了行为安全、工具安全、知识库安全和服务器运行安全。只靠传统网关或敏感词围栏已经不够。

### 建议图示

风险演进图：

`模型问答 -> Agent 调用工具 -> RAG 检索知识库 -> 服务器运行行为 -> 安全运营闭环`

## 第 9 页：模块二 - Prompt 与内容安全检测

### 页面标题

Prompt 与内容安全：从规则拦截升级到 AI 语义检测

### 页面内容

核心功能：

- Prompt 注入检测：识别“忽略以上指令”等指令劫持。
- 越狱检测：识别 DAN、角色扮演、绕过限制等模式。
- 间接注入检测：识别文档、网页、MCP 返回内容中的隐藏指令。
- PII 检测：手机号、身份证、银行卡、邮箱、API Key 等。
- 输出检测：识别违规输出、隐私泄露、有害内容。
- 流式输出处理：流结束后进行完整检测，必要时打标、替换或告警。

### 讲解稿

团队C的围栏更多是敏感词和正则，我们可以把它作为基础能力接入。但我们的平台要向上走一步，把规则、语义检测、风险评分、处置动作和审计证据串起来，形成完整的内容安全治理能力。

### 建议图示

## 第 11 页：模块四 - 动态运行时检测

### 页面标题

运行时检测：看到 Agent 实际做了什么

### 页面内容

核心能力：

- LLM 调用采集：Prompt、Response、Token、模型、延迟。
- MCP/Skill 调用采集：工具名、参数摘要、返回结果、耗时。
- 文件操作监控：OPEN、READ、WRITE、DELETE。
- 命令执行监控：父子进程、命令路径、参数摘要。
- 网络访问监控：源 IP、目的 IP、端口、协议、异常外联。
- Session / Trace 调用链重建。
- 行为序列分析：识别“注入 -> 探测 -> 读取文件 -> 数据外发”。
- 意图对齐审计：判断 Agent 行动是否偏离用户原始任务。

### 讲解稿

网关只能看到经过它的请求，但看不到 Agent 在服务器上读了什么文件、执行了什么命令、连了哪个外网地址。运行时检测补上这部分能力，是我们和普通网关、敏感词围栏最大的区别之一。

### 建议图示

行为链图：`Prompt 注入 -> MCP 调用 -> 文件读取 -> 命令执行 -> 外联网络 -> 告警处置`。

## 第 12 页：模块五 - 知识库与 RAG 安全

### 页面标题

知识库安全：防止 RAG 成为新的攻击入口

### 页面内容

风险场景：

- 文档中藏有恶意 Prompt，Agent 检索后被间接注入。
- 知识库包含身份证、手机号、薪资、合同、密钥等敏感信息。
- 低权限用户通过提问诱导模型输出高权限知识。
- 历史版本或旧文档残留敏感内容。

核心功能：

- 文档上传时安全扫描。
- 已有知识库批量扫描和定期复扫。
- 隐藏指令 / Prompt 注入片段检测。
- PII、敏感词、凭证、内网地址扫描。
- 风险文档状态流转：待扫描、通过、待复核、阻断、豁免。
- 高风险文档不向量化、不参与召回。
- RAG 召回片段二次复检。
- 知识库风险报告和注入来源溯源。

### 讲解稿

知识库安全是非常适合我们切入的差异化方向。很多安全产品关注用户输入，但攻击者也可以把恶意指令藏在知识库文档里，让 Agent 检索后执行。这种间接 Prompt 注入，普通网关很难完整覆盖。

### 建议图示

RAG 风险链路：`文档上传 -> 安全扫描 -> 向量化准入 -> 召回片段复检 -> 模型生成 -> 审计追踪`。

## 第 13 页：模块六 - 统一安全管理控制台

### 页面标题

统一安全运营：从发现风险到处置闭环

### 页面内容

核心页面和功能：

- 安全 Dashboard：活跃 Agent、调用量、安全事件、未处置告警。
- Agent 安全台账：资产状态、风险等级、实例健康、负责人。

# 三、可直接复用的素材

## 1. 一句话定位

> AI 安全平台是一套面向企业 AI 应用和 Agent 的纵深安全防护体系，统一覆盖模型调用入口、Agent 运行行为、MCP/Skill 工具链、知识库/RAG 数据和安全运营闭环。

## 2. 与 Higress 区别话术

> Higress 是通用网关底座，我们复用它的路由、认证、限流、WAF 和插件机制；但我们新增的是 AI 专属能力，包括 Prompt 注入检测、越狱识别、PII 脱敏、Token 成本治理、MCP/Skill 审计、Agent 上下文透传、Trace 证据链和安全策略闭环。因此我们不是简单部署 Higress，而是把 Higress 产品化为 AI 安全平台的实时防护入口。

## 3. 与团队A关系话术

> 团队A负责统一身份、组织、授权和模型资源底座，我们不重复建设这些通用能力；我们接入团队A的底座能力，补齐 AI 应用运行后的安全治理，包括 Agent 行为、MCP/Skill、知识库、Prompt/Response、运行时行为和审计报告。

## 4. 平台价值四句话

- 看得见：发现服务器、容器、Agent、MCP、Skill、知识库等 AI 资产。
- 查得出：扫描 Prompt、配置、工具、文档、凭证和运行时行为风险。
- 拦得住：在网关、SDK、Client Agent 三个位置执行阻断、脱敏、告警和降级。
- 说得清：通过 Trace、审计日志、风险报告、Agent 安全评分说明风险来源和处置结果。

## 6. 可做演示的典型场景

### 场景一：Prompt 注入被网关拦截

流程：

1. 用户提交恶意 Prompt。
2. 网关防护子系统调用输入检测。
3. 检测引擎识别为 Prompt 注入。
4. 网关执行 BLOCK。
5. 控制台生成风险事件和审计记录。

演示价值：说明网关防护实时能力。

### 场景二：知识库文档投毒

流程：

1. 用户上传 PDF/Markdown 文档到知识库。
2. AI 安全平台触发文档扫描。
3. 检测到隐藏指令或敏感信息。
4. 文档状态变为待复核或阻断。
5. 不进入向量化，不参与 RAG 召回。

演示价值：说明知识库安全差异化。

### 场景三：Agent 被注入后调用高危工具

流程：

1. Agent 收到诱导指令。
2. Agent 尝试调用 MCP 高危工具。
3. 网关或权限服务拦截工具调用。
4. 运行时检测记录调用链。
5. 控制台还原攻击链。

演示价值：说明 Agent 行为链和 MCP/Skill 安全。

### 场景四：服务器侧异常行为

流程：

1. Agent 进程读取敏感文件或执行外联命令。
2. Client Agent/探针采集文件、命令、网络行为。
3. 安全治理中心规则命中。
4. 告警并关联到 Agent、Session、Trace。

演示价值：说明我们能看到网关看不到的主机侧风险。
